# VS Code Copilot 에이전트 창 개요

## 개요

Agents 창은 에이전트 중심(Agent-first) 워크플로를 위해 설계된 VS Code 전용 창입니다. 채팅과 세션 목록을 중심으로 여러 프로젝트에서 에이전트 세션을 관리하고, 커스터마이제이션을 한 곳에서 볼 수 있습니다.

## 사전 요구 사항

- VS Code 설치
- GitHub Copilot 액세스 및 구독
- Copilot이 설정된 GitHub 인증

## 코드 중심 vs 에이전트 중심

- 코드 중심(Code-first)
  - 편집기에서 코드를 작성하며 AI를 보조 도구로 사용합니다.
  - 편집, 테스트, 디버깅이 주요 인터페이스입니다.
- 에이전트 중심(Agent-first)
  - 채팅으로 고수준 작업을 지시하고 에이전트가 계획, 구현, 검증을 수행합니다.
  - 채팅과 세션 관리가 주요 인터페이스입니다.

Agents 창은 에이전트 중심 워크플로에 최적화되어 있으며, 메인 편집기 창과 설정 및 세션을 공유합니다.

## Agents 창 열기

- VS Code 타이틀 바의 `Open in Agents` 버튼 선택
- 명령 팔레트에서 `Chat: Open Agents Window` 실행 (`Ctrl+Shift+P`)
- 명령줄에서 `code --agents` 실행
- 브라우저에서 `https://insiders.vscode.dev/agents` 열기

Agents 창은 GitHub 인증을 필요로 하며, VS Code에 이미 로그인된 경우 자동으로 연동됩니다.

## 인터페이스 구성

Agents 창의 주요 영역:

1. 세션 목록: 사이드바에서 여러 작업공간의 세션을 그룹화하여 관리합니다.
2. 커스터마이제이션 패널: 에이전트 행동을 조정하는 사용자 정의 옵션에 접근합니다.
3. 채팅 영역: 에이전트와 대화하며 작업을 지시하고 결과를 확인합니다.
4. 변경 사항 패널: 세션 중 생성된 파일 변경 및 워크스페이스 파일 탐색기를 확인합니다.

## 에이전트 세션 시작

1. 사이드바 상단의 `New` 버튼 또는 `Ctrl+N`을 눌러 새 세션 시작.
2. 작업공간 드롭다운에서 로컬 폴더 또는 GitHub 리포지토리를 선택.
3. 에이전트 유형 선택.
4. 프롬프트 입력 후 Enter.

에이전트 유형은 선택한 작업공간에 따라 달라집니다:

- 폴더: Copilot CLI 또는 Claude 에이전트 선택 가능
- 리포지토리: Copilot 클라우드 에이전트 세션

Copilot CLI 세션에서는 작업 트리 격리 또는 폴더 격리를 선택할 수 있습니다.

## 변경 사항 관리 및 검토

- Changes 패널에서 파일 변경 내용을 확인하고 에이전트가 수정한 파일을 검토합니다.
- Files 탭은 워크스페이스 파일 탐색기를, Changes 탭은 변경된 파일 목록을 보여줍니다.
- 파일을 선택해 diff 뷰로 변경 내용을 비교할 수 있습니다.
- 변경 사항 내에서 `Add Feedback`를 사용해 에이전트에게 직접 피드백을 줄 수 있습니다.

변경 사항 처리 옵션:

- Commit: 폴더 격리에서 변경 사항을 커밋
- Merge: 작업 트리 격리에서 변경 사항 병합 및 PR 생성
- Checkout: Copilot Cloud 세션의 브랜치를 로컬에서 확인
- Discard: 변경 사항 폐기

세션 생성 시 Files 패널의 동기화 버튼으로 기준 브랜치의 최신 상태를 가져올 수 있습니다.

## 로컬 검증

- 에이전트가 만든 변경 내용을 커밋 또는 병합 전에 로컬에서 빌드/테스트로 검증할 수 있습니다.
- 작업 트리 세션의 컨텍스트에서 실행할 작업(task)을 구성합니다.
- `Add Task`로 작업 이름, 명령, 자동 실행 옵션, 저장 위치를 지정합니다.
- 통합 브라우저를 사용해 `localhost` 링크를 Agents 창에서 열어 상태를 유지할 수 있습니다.
- 통합 터미널을 열어 현재 세션의 작업 디렉터리에서 명령을 실행할 수 있습니다.

## 원격 머신에서 세션 열기

### SSH 연결

- 원격 머신이 SSH로 접근 가능해야 함.
- `New` 또는 `Ctrl+N`으로 새 세션 시작 후 작업공간 드롭다운에서 Remote > SSH 선택.
- SSH 연결 문자열 입력 후 원격 폴더 선택.
- 프롬프트 입력 후 세션 시작.

### Dev Tunnel 연결

- 원격 머신에서 dev tunnel이 실행 중이어야 함.
- `New` > Remote > Tunnels 선택 후 계정 유형 선택.
- 활성 터널과 원격 폴더 선택.
- 프롬프트 입력 후 세션 시작.

Dev Tunnel은 GitHub 또는 Microsoft 인증을 요구하며, 익명 액세스를 허용하면 보안 위험이 있습니다.

## 브라우저에서 Agents 창 사용

- `https://insiders.vscode.dev/agents`에서 브라우저 기반 Agents 창을 사용합니다.
- 원격 호스트의 dev tunnel을 통해 접속.
- 브라우저 창은 세션 관리를 위한 경량 클라이언트 역할을 합니다.
- 호스트 바에서 터널 호스트의 상태(온라인/오프라인)를 확인하고 연결을 관리할 수 있습니다.

## 서브 세션 생성

- 활성 세션에서 `New Sub-Session (+)`을 사용해 별도의 병렬 작업을 시작합니다.
- 서브 세션은 동일한 작업공간과 작업 트리를 공유하지만 채팅 기록은 새로 시작됩니다.
- 특정 작업을 별도 흐름으로 탐색할 때 유용합니다.

## 세션 관리

- 세션 목록에서 활성 세션을 탐색하고 검색, 필터링, 그룹화를 사용할 수 있습니다.
- 세션별 이름, 작업공간, 에이전트 유형, 변경 통계를 확인합니다.
- 세션을 마우스 오른쪽 버튼으로 클릭해 이름 변경, 완료 표시, 고정 등 추가 작업을 수행합니다.
- 세션 간 빠른 탐색을 위해 제목 표시줄의 화살표 버튼을 사용합니다.

## 프로젝트 및 워크플로 사용자화

- Customizations 패널에서 에이전트, Skills, Instructions, Hooks, MCP Servers, Plugins 등을 관리합니다.
- 워크스페이스 수준 또는 사용자 전체 수준에서 커스터마이제이션을 추가/편집/활성화/비활성화할 수 있습니다.
- 패널 상단 왼쪽 드롭다운에서 적용 대상 에이전트를 선택합니다.

## 폴더 신뢰

- 새 폴더나 리포지토리를 처음 열 때 신뢰 여부를 묻습니다.
- 신뢰하지 않으면 해당 폴더에서 에이전트 세션을 시작하거나 계속할 수 없습니다.
- Agents 창과 메인 VS Code 창은 동일한 작업공간 신뢰 상태를 공유합니다.

## GitHub 계정 전환

- 창 오른쪽 상단의 계정 아이콘을 클릭하여 로그아웃하고 다른 GitHub 계정으로 로그인할 수 있습니다.

## Agents 창 설정

- Agents 창은 VS Code 설정을 공유합니다.
- Agents 창만의 동작을 원할 경우 설정 파일에서 Agents 창 범위로 값을 오버라이드할 수 있습니다.
- Agents 창에서 설정 편집기(`Ctrl+,`)로 범위 적용 상태를 확인할 수 있습니다.

## 확장 기능 사용

- Agents 창은 확장 기능을 실행할 수 있습니다.
- 테마, 문법, 언어, 키바인딩과 같은 정적 콘텐츠 확장은 자동 활성화됩니다.
- 일부 확장 기능은 기본 프로필에 설치되어 있어야 하며, `extensions.supportAgentsWindow` 설정으로 Agents 창에서 활성화할 수 있습니다.
- 확장 지원은 계속 발전 중이므로 예상대로 동작하지 않으면 이슈 제출이 권장됩니다.

## 제한 사항

- 통합 브라우저를 직접 열 수는 없으며, 명령 팔레트에서 수동으로 열어야 합니다.
- 현재 지원되는 에이전트 유형은 Copilot CLI, Copilot Cloud, Claude 에이전트입니다.
- GitHub 리포지토리 기반이 아닌 경우 Copilot CLI만 사용할 수 있습니다.
- 에이전트 드롭다운에 Plan 에이전트가 표시되지 않습니다. Copilot CLI 또는 Claude 세션에서 `/plan` 명령을 사용하면 계획 에이전트 기능을 사용할 수 있습니다.
- Claude 에이전트 세션에서는 서브 세션을 사용할 수 없습니다.
- 멀티 루트 세션은 아직 지원되지 않습니다.
