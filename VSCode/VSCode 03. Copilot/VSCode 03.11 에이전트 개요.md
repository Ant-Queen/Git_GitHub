# VS Code Copilot 에이전트 개요

## 에이전트란?

에이전트는 코딩 작업을 자율적으로 수행하는 AI 도우미입니다. 높은 수준의 목표를 제시하면 에이전트는 작업을 단계로 나누고, 파일을 편집하고, 명령을 실행하며, 문제가 생기면 스스로 수정합니다.

## 에이전트 작업 방식

- 에이전트는 편집기 내에서 사용자와 상호작용하며 워크스페이스, 도구, 모델에 대한 액세스를 활용합니다.
- 로컬 또는 클라우드에서 실행할 수 있으며, 특정 작업에 맞는 에이전트 유형을 선택할 수 있습니다.
- 세션은 단일 대화형 흐름으로 유지되며 작업 진행 상황이 기록됩니다.
- 에이전트는 작업을 수행하면서 필요한 경우 자체 수정 및 재시도를 할 수 있습니다.

## 작업 환경 선택

VS Code에서는 두 가지 주요 에이전트 작업 환경을 제공합니다.

- 메인 편집기 창
  - 코드 작성, 디버거, 노트북, 확장 기능과 함께 사용할 수 있는 기존 편집기 환경입니다.
  - 채팅, 인라인 제안, 에이전트 세션을 통해 AI 도움을 받습니다.
- Agents 창(미리 보기)
  - 에이전트 중심 작업을 위한 전용 창입니다.
  - 여러 프로젝트 간 에이전트 세션을 관리하고, 변경 사항과 커스터마이제이션을 한곳에서 볼 수 있습니다.

두 환경은 동일한 세션, 설정, 단축키를 공유하므로 자유롭게 전환할 수 있습니다.

## 에이전트 유형

에이전트는 다음과 같은 환경에서 실행됩니다.

- 로컬 에이전트
  - VS Code 내부에서 인터랙티브하게 실행됩니다.
  - 워크스페이스, 도구, 모델에 완전한 접근 권한을 갖습니다.
- Copilot CLI
  - 로컬 머신에서 백그라운드로 실행됩니다.
  - Git worktree와 함께 격리된 실행을 지원합니다.
- 클라우드 에이전트
  - 원격에서 실행되며 GitHub Pull Request 통합을 제공합니다.
- 서드파티 에이전트
  - Anthropic, OpenAI 같은 외부 AI 제공업체의 에이전트를 활용합니다.

### 어떤 에이전트를 선택해야 하나?

- 아이디어를 브레인스토밍하거나 탐색하고 싶을 때: 로컬 에이전트
- 코드베이스 질문에 답이 필요할 때: 로컬 에이전트(Ask)
- 구조화된 구현 계획을 만들 때: 로컬 에이전트(Plan)
- 테스트 실패, 린트 오류, 디버그 출력 등을 해결할 때: 로컬 에이전트
- 통합 브라우저로 웹 앱을 빌드하거나 테스트할 때: 로컬 에이전트
- 특정 VS Code 확장 도구 또는 MCP 서버를 사용해야 할 때: 로컬 에이전트
- 잘 정의된 작업을 수행하면서 계속 작업을 유지하려면: Copilot CLI 또는 클라우드 에이전트
- 여러 변형이나 개념 증명을 탐색하려면: Copilot CLI 또는 클라우드 에이전트
- 여러 프로젝트에서 에이전트 세션을 조율하려면: Agents 창
- 팀 검토를 위해 PR을 생성하려면: 클라우드 에이전트
- GitHub 이슈를 에이전트에 할당하려면: 클라우드 에이전트
- 특정 AI 제공업체를 선택하려면: 서드파티 에이전트

## 에이전트 선택

에이전트 유형은 에이전트가 작업을 수행하는 환경을 결정합니다. 에이전트 자체는 역할 또는 페르소나에 따라 행동합니다.

- 코드 리뷰어 페르소나: 코드 품질과 스타일에 집중하여 피드백을 제공하고 직접 변경을 최소화합니다.
- 각 에이전트 정의는 사용 가능한 도구, 실행 방식, 다른 에이전트로의 전환 지점을 결정합니다.

### 기본 내장 에이전트

- Agent
  - 자율적으로 계획을 세우고 파일 간 변경을 수행하며 터미널 명령과 도구를 호출합니다.
- Plan
  - 코드를 작성하기 전에 구조화된 단계별 구현 계획을 만듭니다.
  - 계획이 적절해 보이면 구현 에이전트에 전달합니다.
- Ask
  - 코드베이스, 코딩 개념, VS Code 관련 질문에 답합니다.
  - 파일 변경을 수행하지 않습니다.

### 커스텀 에이전트

- 특정 역할, 사용 가능한 도구, 언어 모델을 정의하여 맞춤형 워크플로를 구성합니다.
- 프로젝트 또는 팀 요구에 맞는 에이전트를 생성할 수 있습니다.

## 권한 수준 선택

에이전트가 도구 및 터미널 명령을 호출하는 방식에 대한 자율성을 조절할 수 있습니다.

- Default Approvals
  - VS Code 설정에 지정된 승인 규칙을 따릅니다.
  - 기본적으로 읽기 전용 및 안전한 도구만 명시적 승인 없이 실행됩니다.
- Bypass Approvals
  - 모든 도구 호출을 자동 승인합니다.
  - 에이전트가 작업 중에 명확한 질문을 할 수 있습니다.
- Autopilot (Preview)
  - 모든 도구 호출을 자동 승인하고, 질문에 자동 응답하며 작업을 자율적으로 계속합니다.

권한 수준 기본값을 세션마다 유지하려면 `chat.permissions.default` 설정을 구성합니다.

## 세션 핸드오프

에이전트 간 작업을 전환하여 각 에이전트의 강점을 활용할 수 있습니다.

- 로컬 에이전트에서 다른 에이전트 유형으로 전환하면 전체 대화 기록과 컨텍스트가 새 세션으로 이어집니다.
- 원래 세션은 보관됩니다.
- Copilot CLI 세션에서는 `/delegate` 명령을 사용하여 클라우드 에이전트에 위임할 수 있습니다.
- 예: 로컬 에이전트로 계획을 만든 뒤 Copilot CLI로 증명 개념을 수행하고, 클라우드 에이전트로 PR을 제출합니다.

### 에이전트에 작업 할당

- GitHub Pull Requests 확장 기능을 설치하면 코드의 `TODO` 주석을 에이전트에 할당할 수 있습니다.
- GitHub.com 또는 확장 기능을 통해 `copilot`으로 이슈를 할당하거나 댓글에 언급하여 코드 리뷰를 요청할 수 있습니다.
