# VS Code Copilot 도구 개요 정리

## 개요

Copilot에서 도구는 모델이 실제 작업을 수행할 수 있도록 하는 메커니즘입니다. 모델은 텍스트만 생성하는 대신 도구를 호출하여 파일을 읽고 쓰거나, 터미널 명령을 실행하거나, 코드베이스를 검색하고, 외부 서비스와 연결합니다.

## 도구의 유형

1. 내장 도구(Built-in tools)
   - VS Code에 기본 제공됩니다.
   - 파일 읽기/쓰기, 터미널 명령 실행, 코드 검색, 편집기 탐색 같은 일반 개발 작업을 지원합니다.
   - 별도 설정 없이 즉시 사용 가능합니다.

2. MCP 도구(MCP tools)
   - Model Context Protocol(MCP) 서버가 제공하는 도구입니다.
   - MCP는 AI 모델을 외부 도구 및 데이터 소스에 연결하는 오픈 표준입니다.
   - 로컬 머신에서 실행하거나 원격으로 호스트할 수 있습니다.
   - 데이터베이스, API, 기타 외부 서비스에 연결할 때 사용합니다.

3. 확장 도구(Extension tools)
   - VS Code 확장이 Language Model Tools API를 통해 제공하는 도구입니다.
   - 설치된 확장이 도구를 기여하면, 에이전트는 해당 도구를 사용할 수 있습니다.

## 도구는 어떻게 작동하나

- 에이전트가 작업을 처리할 때 모델은 사용 가능한 도구를 검토하고 적절한 도구를 호출합니다.
- 이는 자율적으로 이루어집니다. 사용자는 높은 수준의 작업만 지시하면 됩니다.
- 프롬프트에서 `#도구이름`처럼 명시적으로 도구를 참조해 특정 도구 사용을 유도할 수도 있습니다.

## 사용 가능한 도구 제어하기

- 채팅 입력창의 `Configure Tools` 버튼으로 현재 요청에 사용할 도구를 개별적으로 활성화하거나 비활성화할 수 있습니다.
- 도구 사용을 제한하면 다음과 같은 장점이 있습니다.
  - 컨텍스트 보존: 도구 호출 출력은 컨텍스트 윈도우를 사용하므로 불필요한 도구 호출을 줄이면 공간을 절약합니다.
  - 크레딧 절약: 불필요한 호출은 토큰 사용량을 증가시키고 AI 크레딧을 소비합니다.
  - 더 적합한 결과: 도구 수가 적으면 모델이 가장 적절한 도구에 집중합니다.
  - 성능 향상: 도구 선택 범위가 좁아져 응답 속도가 빨라질 수 있습니다.

- [프롬프트 파일](https://code.visualstudio.com/docs/copilot/customization/prompt-files)과 [커스텀 에이전트](https://code.visualstudio.com/docs/copilot/customization/custom-agents)를 통해 특정 작업이나 워크플로에 고정된 도구 세트를 정의할 수도 있습니다.

## 도구 승인 및 신뢰

도구는 파일, 환경, 외부 서비스에 영향을 줄 수 있으므로 보안 제어가 제공됩니다.

- 승인 프롬프트: 부작용이 있는 도구는 실행 전에 확인 대화 상자를 표시합니다.
  - 한 번만 허용
  - 현재 세션 동안 허용
  - 향후 모든 호출 허용
- URL 승인: 도구가 URL에 접근할 때는 요청과 응답 내용을 모두 검증하는 2단계 프로세스가 적용됩니다.
- 권한 수준: 에이전트가 자동으로 얼마나 많은 권한을 가질지를 결정합니다.
  - 수동 승인 필요
  - 부분 자동화
  - 완전 자율 운영
