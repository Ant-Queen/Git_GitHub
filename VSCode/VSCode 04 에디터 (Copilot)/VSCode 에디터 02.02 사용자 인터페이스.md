# VSCode 에디터 02.02 사용자 인터페이스

## 한줄 요약
VS Code의 화면은 편집기, 사이드 바, 패널, 상태 표시줄로 나뉘며, 각 영역을 이해하면 작업 흐름이 훨씬 편해집니다.

## 핵심 개념
- Activity Bar: 왼쪽에 있어 보기(Explorer, Search, Source Control, Extensions 등)를 전환합니다.
- Primary Side Bar: 선택한 보기의 세부 내용을 보여줍니다.
- Editor: 파일 내용을 직접 수정하는 핵심 영역입니다.
- Panel: 터미널, 문제, 출력 결과 등을 확인하는 하단 영역입니다.
- Status Bar: 현재 파일, 언어 모드, Git 상태, 오류 수 등을 보여줍니다.

## 주요 기능
- 에디터를 수평/수직으로 분할해 여러 파일을 동시에 볼 수 있습니다.
- 사이드 바 위치를 바꾸거나 숨길 수 있습니다.
- 탭, 미니맵, Breadcrumbs, Sticky Scroll 등으로 코드 탐색이 쉬워집니다.
- Command Palette를 통해 대부분의 기능을 키보드로 실행할 수 있습니다.

## 실무 팁
- Ctrl+Shift+P로 명령 팔레트를 자주 열어보세요.
- Ctrl+B로 사이드 바, Ctrl+J로 패널을 토글할 수 있습니다.
- 화면이 좁으면 패널이나 사이드 바를 숨겨 집중도를 높일 수 있습니다.

## 핵심 정리
VS Code UI는 “편집에 집중”할 수 있게 설계돼 있고, 필요할 때만 다른 영역을 열어 쓰는 구조입니다.
