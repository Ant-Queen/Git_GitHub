# VSCode 에디터 02.06 AI 기반 제안

## 한줄 요약
GitHub Copilot를 활용하면 VS Code에서 코드 자동완성뿐 아니라 다음 수정 제안, 코드 설명, 오류 수정까지 AI로 보조받을 수 있습니다.

## 핵심 개념
- Ghost text 제안: 입력 중에 코드 조각을 dimmed 텍스트로 제안합니다.
- Next Edit Suggestions: 지금 하고 있는 편집 흐름에 맞춰 다음 수정 위치와 내용을 예측해 제안합니다.
- 스마트 액션: 코드 설명, 테스트 생성, 문서 생성, 오류 수정 같은 작업을 클릭 한 번으로 실행할 수 있습니다.
- Copilot은 현재 열려 있는 파일과 문맥을 보고 제안을 생성합니다.

## 자주 쓰는 기능
- Tab으로 제안 수락
- 코드 주석을 넣어 원하는 구현 방향을 힌트로 제공
- 코드 선택 후 “Explain”, “Fix”, “Generate Tests” 같은 스마트 액션 사용
- Inline Suggestion 설정을 통해 제안 표시 여부와 모델 변경 가능

## 실무 팁
- AI 제안은 문맥이 풍부할수록 더 정확해집니다.
- 처음엔 작은 코드 조각에 대해 제안을 받아보며 익히는 것이 좋습니다.
- 과도한 제안이 부담되면 설정에서 켜고 끌 수 있습니다.

## 핵심 정리
AI 기반 제안은 단순 자동완성을 넘어, 코드를 작성하고 수정하는 흐름 전체를 보조하는 기능입니다.
