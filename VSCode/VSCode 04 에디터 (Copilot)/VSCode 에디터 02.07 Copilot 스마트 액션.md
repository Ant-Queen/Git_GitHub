# VSCode 에디터 02.07 Copilot 스마트 액션

## 한줄 요약
Copilot Smart Actions는 AI를 이용해 코드 설명, 테스트 생성, 오류 수정, 문서화, 커밋 메시지 생성 같은 반복 작업을 더 쉽게 해줍니다.

## 핵심 개념
- “프롬프트를 직접 쓰지 않아도” AI가 적절한 액션으로 도움을 줄 수 있습니다.
- 코드에 대한 설명, 리팩토링 제안, 테스트 생성, 오류 수정이 가능합니다.
- Git 작업과 연결되면 커밋 메시지나 PR 설명도 자동화할 수 있습니다.
- 검색, 설정, 터미널 오류까지 AI 지원 범위가 넓습니다.

## 대표 예시
- 코드 선택 후 Explain
- 코드 선택 후 Fix
- Generate Tests
- Generate Docs
- Generate Commit Message
- Review Code

## 실무 팁
- 작은 코드 블록부터 시도하면 이해하기 쉽습니다.
- 테스트 생성이나 설명 생성은 반복 작업을 줄이는 데 특히 유용합니다.
- AI 결과는 참고용으로 보고, 최종 검토는 사람이 해야 합니다.

## 핵심 정리
스마트 액션은 AI를 “대화형 도구”로 쓰기보다, 실무 작업 흐름 안에 자연스럽게 넣는 기능입니다.
