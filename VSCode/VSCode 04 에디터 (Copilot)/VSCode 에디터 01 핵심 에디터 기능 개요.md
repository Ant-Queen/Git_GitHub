# VSCode 에디터 01 핵심 에디터 기능 개요

## 한줄 요약
Visual Studio Code는 코드를 작성하고, 실행하고, 디버깅하고, Git으로 관리하는 데 필요한 핵심 기능을 기본부터 잘 갖춘 편집기입니다.

## 핵심 개념
- VS Code는 단순한 텍스트 편집기라기보다, 개발 생산성을 높이는 통합 개발 환경입니다.
- 기본 기능으로는 설정, 확장, 단축키, 프로필 관리가 있습니다.
- 코드 편집 기능으로는 IntelliSense, 코드 이동, 리팩토링, 스니펫이 있습니다.
- 빌드, 디버깅, 테스트, Git 관리, 터미널까지 한 곳에서 처리할 수 있습니다.

## 주요 영역

### 1) 설정하고 커스터마이즈하기
- 키보드 단축키를 바꿀 수 있습니다.
- 설정을 조정해 작업 방식에 맞게 바꿀 수 있습니다.
- 확장 기능을 설치해 언어, 도구, 테마를 추가할 수 있습니다.
- 프로젝트별로 다른 프로필을 만들어 관리할 수 있습니다.

### 2) 코드 편집하기
- 자동완성 기능인 IntelliSense를 사용해 빠르게 코드를 작성할 수 있습니다.
- 코드 이동 기능으로 함수나 클래스 위치를 쉽게 찾을 수 있습니다.
- 리팩토링 도구로 코드 구조를 정리할 수 있습니다.
- 자주 쓰는 코드 조각은 스니펫으로 저장해 재사용할 수 있습니다.

### 3) 빌드, 디버깅, 테스트하기
- 작업 자동화를 위한 태스크를 실행할 수 있습니다.
- 내장 디버거로 코드 실행 흐름을 추적할 수 있습니다.
- 테스트를 바로 실행해 오류를 확인할 수 있습니다.

### 4) 소스 컨트롤 관리하기
- Git 기능이 내장되어 있어 변경 사항을 관리하기 쉽습니다.
- 스테이징, 커밋, 브랜치 관리, 병합 충돌 해결을 편집기 안에서 할 수 있습니다.
- GitHub와 연동해 협업도 비교적 쉽게 할 수 있습니다.

### 5) 터미널 사용하기
- 편집기 안에서 터미널을 열어 명령을 실행할 수 있습니다.
- 터미널 프로필과 셸 통합 기능을 활용해 작업 효율을 높일 수 있습니다.

## 실무 팁
- 처음에는 기본 설정과 확장 기능부터 정리하는 것이 가장 좋습니다.
- 자동완성과 코드 이동 기능을 익히면 코딩 속도가 크게 빨라집니다.
- Git과 터미널 기능을 익혀 두면 개발 흐름이 훨씬 자연스러워집니다.

## 핵심 정리
VS Code는 “코드 편집기”를 넘어서, 개발 전반을 하나의 흐름으로 처리할 수 있게 해주는 통합 도구입니다.
