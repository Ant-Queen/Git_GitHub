# VSCode 에디터 02.05 IntelliSense

## 한줄 요약
IntelliSense는 코드 자동완성, 파라미터 정보, 타입 정보, 심볼 탐색을 제공해 개발 생산성을 높여주는 핵심 기능입니다.

## 핵심 개념
- 언어 서비스가 코드 맥락을 분석해 자동완성 제안을 보여줍니다.
- JavaScript, TypeScript, JSON, HTML, CSS 등은 기본적으로 강력한 IntelliSense를 제공합니다.
- 언어 확장 프로그램을 설치하면 더 많은 언어와 프레임워크에 대해 지원받을 수 있습니다.
- 자동완성은 단순한 단어 추천뿐 아니라 함수 시그니처와 문서도 함께 보여줍니다.

## 주요 기능
- Ctrl+Space로 수동으로 열기
- Tab, Enter로 제안 수락
- 파라미터 힌트 보기
- 정의로 이동(F12), 참조 찾기(Shift+F12)
- AI 보조 기능과도 연결 가능

## 실무 팁
- 자동완성은 코드 작성 속도를 높이므로 꼭 익혀두면 좋습니다.
- 타입 정보가 잘 보이는 언어에서는 더 정확한 제안을 기대할 수 있습니다.
- IntelliSense가 안 보이면 확장 기능이나 언어 서비스 상태를 먼저 확인하세요.

## 핵심 정리
IntelliSense는 “코드를 더 빨리 치게 해 주는 도구”이자, “코드 구조를 더 잘 이해하게 해 주는 도구”입니다.
