# VSCode 에디터 02.03 팁과 요령

## 한줄 요약
VS Code의 다양한 단축키와 팁을 잘 알면 코딩 속도와 집중도를 크게 높일 수 있습니다.

## 핵심 개념
- Welcome 페이지와 Walkthrough를 통해 VS Code 기능을 단계적으로 배울 수 있습니다.
- Command Palette는 거의 모든 명령을 찾는 진입점입니다.
- 터미널, 사이드 바, 패널, Zen 모드 같은 기능은 작업 몰입도를 높여줍니다.
- 키보드 단축키를 익히면 마우스보다 훨씬 빠르게 작업할 수 있습니다.

## 유용한 기능
- Ctrl+Shift+P: 명령 팔레트
- Ctrl+`: 통합 터미널
- Ctrl+B: 사이드 바 토글
- Ctrl+J: 패널 토글
- Ctrl+K Z: Zen Mode
- Ctrl+P: 빠른 파일 열기

## 실무 팁
- 처음부터 모든 단축키를 외우기보다, 자주 쓰는 기능부터 익히는 것이 좋습니다.
- Quick Open와 Command Palette는 매우 강력한 생산성 도구입니다.
- Zen Mode는 집중이 필요할 때 유용합니다.

## 핵심 정리
VS Code는 단축키와 UI 토글 기능을 잘 활용하면 “빠르고 몰입감 있는 편집 경험”을 만들 수 있습니다.
