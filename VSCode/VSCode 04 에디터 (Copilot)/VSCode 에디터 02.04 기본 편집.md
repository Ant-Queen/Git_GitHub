# VSCode 에디터 02.04 기본 편집

## 한줄 요약
VS Code의 기본 편집 기능은 멀티커서, 찾기/바꾸기, 자동 저장, 인덴트 관리, 비교 기능까지 포함해 실무에서 매우 자주 쓰입니다.

## 핵심 개념
- 멀티커서: 여러 위치에 동시에 편집할 수 있어 반복 작업을 빠르게 처리합니다.
- 찾기/바꾸기: 현재 파일뿐 아니라 전체 워크스페이스에서도 검색할 수 있습니다.
- Auto Save: 저장을 자동화해 작업 흐름을 매끄럽게 만들 수 있습니다.
- Hot Exit: 종료 전 수정 내용을 기억해 다음 실행 시 복구해 줍니다.
- 비교 기능: 두 파일 또는 현재 파일과 저장본/클립보드를 비교할 수 있습니다.

## 자주 쓰는 기능
- Ctrl+D: 다음 같은 단어를 선택
- Ctrl+Alt+위/아래: 멀티커서 추가
- Ctrl+F: 현재 파일 찾기
- Ctrl+Shift+F: 워크스페이스 전체 검색
- Ctrl+S: 저장
- Ctrl+K Ctrl+S: 키바인딩 설정

## 실무 팁
- 반복되는 코드 변경은 멀티커서를 쓰면 훨씬 빠릅니다.
- 대규모 변경 전에는 검색/바꾸기 기능으로 영향 범위를 먼저 확인하세요.
- Auto Save를 켜두면 실수로 저장을 놓치는 일을 줄일 수 있습니다.

## 핵심 정리
기본 편집 기능을 익히면 단순 텍스트 입력보다 훨씬 빠르고 정확하게 코드를 다룰 수 있습니다.
