# VSCode 에디터 03.08 프로필 (Profiles)

## 한줄 요약
프로필은 설정, 확장, 테마, 상태 등을 묶어 여러 작업 환경(예: 개인/회사/프로젝트) 간에 빠르게 전환할 수 있게 해주는 기능입니다.

## 핵심 개념
- 프로필은 `Settings`, `Extensions`, `UI State`, `Snippets`, `Keybindings` 등을 캡슐화합니다.
- 기본 프로필 외에 사용자 정의 프로필을 생성하거나 임시(Transient) 프로필을 사용할 수 있습니다.
- 프로필은 내보내기/가져오기 기능으로 다른 기기나 팀원과 공유 가능합니다.

## 주요 기능
- `Manage Profiles` 메뉴로 프로필 생성, 전환, 삭제 가능.
- 프로필 간 전환 시 해당 프로필의 설정과 활성 확장이 적용됨.
- 프로필을 파일로 내보내거나 URL로 공유해 다른 환경에서 불러올 수 있음.

## 실무 팁
- 업무용/개인용 프로필을 분리하면 확장 충돌이나 설정 혼선을 줄일 수 있습니다.
- 프로젝트별로 필요한 확장만 포함한 프로필을 만들어 빠르게 개발 컨텍스트를 전환하세요.
- 프로필을 공유할 때는 민감한 설정(토큰, 개인 정보 등)이 포함되지 않도록 주의하세요.

## 핵심 정리
프로필은 여러 개발 환경을 깔끔하게 분리·관리할 수 있는 강력한 도구입니다. 자주 사용하는 환경을 프로필로 저장해 생산성을 높이세요.
