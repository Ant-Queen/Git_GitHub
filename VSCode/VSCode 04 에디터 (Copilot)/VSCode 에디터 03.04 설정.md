# VSCode 에디터 03.04 설정 (Settings)

## 한줄 요약
사용자, 워크스페이스, 폴더 수준에서 동작하는 각종 설정을 UI 또는 JSON으로 구성하는 방법을 설명합니다.

## 핵심 개념
- 설정은 세 가지 범위: 사용자(User), 워크스페이스(Workspace), 폴더(Folder).
- 설정 편집기는 검색, 추천값, 설명을 제공하며, 고급 사용자는 `settings.json`을 직접 편집할 수 있습니다.
- 언어별 설정을 사용해 특정 언어에만 적용되는 옵션을 지정할 수 있습니다.

## 주요 기능
- `Settings` UI에서 키워드 검색 및 값 변경 가능.
- `Open Settings (JSON)`으로 직접 편집: 예) `"editor.tabSize": 2`.
- 설정 동작 우선순위: Workspace > User > Default.
- 설정 동기화(옵션으로) 및 확장별 설정 접근 지원.

## 실무 팁
- 프로젝트별 규칙(예: 탭 크기, 포맷터 설정)은 워크스페이스 수준에 저장해 팀 간 일관성을 유지하세요.
- `settings.json`에 민감한 데이터(토큰 등)를 넣지 마세요; 환경 변수나 별도 비밀 저장소 사용 권장.
- 설정 검색어로 설정 키 이름을 빠르게 찾으면 문서 확인 시간을 줄일 수 있습니다.

## 핵심 정리
설정은 UI와 JSON 두 방식으로 관리되며, 범위별로 저장 위치와 우선순위가 다릅니다. 팀 규칙은 워크스페이스 레벨에서 관리하세요.
