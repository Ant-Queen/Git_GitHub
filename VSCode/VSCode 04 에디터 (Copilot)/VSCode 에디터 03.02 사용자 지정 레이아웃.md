# VSCode 에디터 03.02 사용자 지정 레이아웃 (Custom Layout)

## 한줄 요약
에디터, 사이드바, 패널 등 UI 구성요소의 위치와 레이아웃을 사용자화하는 방법을 설명합니다.

## 핵심 개념
- VS Code는 에디터 그룹(탭 영역), 사이드바(활동 표시줄), 패널(터미널/출력 등)을 조합해 레이아웃을 구성합니다.
- 에디터 그룹은 수평/수직 분할로 여러 편집 영역을 만들 수 있습니다.
- 패널과 사이드바의 위치는 명령 또는 드래그로 변경 가능합니다.

## 주요 기능
- `View` 메뉴 및 아이콘 드래그로 사이드바/패널을 이동.
- `Split Editor`로 편집기 그룹 생성, `Move Editor into Next Group` 등 명령으로 이동.
- Grid layout: 여러 편집기 그룹을 격자 형태로 배치 가능.
- `Toggle Panel Position`으로 패널을 하단 또는 우측으로 전환.

## 실무 팁
- 코드와 문서, 터미널을 자주 교차해 볼 때는 2~3개의 고정된 에디터 그룹을 만들어 두면 생산성이 오릅니다.
- 화면이 작은 노트북에서는 패널을 우측으로 이동해 세로 공간을 확보하세요.
- 자주 사용하는 뷰(Explorer, Search, Git 등)는 Activity Bar에서 순서를 조정해 빠르게 접근하세요.

## 핵심 정리
레이아웃은 드래그·명령으로 유연하게 변경 가능하며, 팀 규약이나 개인 워크플로에 맞춰 미리 배치해 두면 작업 효율이 높아집니다.
