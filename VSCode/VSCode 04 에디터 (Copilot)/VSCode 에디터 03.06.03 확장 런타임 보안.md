# VSCode 에디터 03.06.03 확장 런타임 보안 (Extension Runtime Security)

## 한줄 요약
확장이 실행될 때 발생할 수 있는 보안 위험과 이를 완화하는 방법(권한, 샌드박스 등)을 설명합니다.

## 핵심 개념
- 확장은 Extension Host 프로세스에서 실행되며, 시스템에 접근할 수 있는 능력이 있어 잠재적 위험이 존재합니다.
- 권한 모델과 실행 제약, Marketplace 검증, 사용자 동의(설정 등)를 통해 위험을 줄입니다.
- 신뢰되지 않은 확장은 비활성화하거나 제한된 환경에서 실행해야 합니다.

## 주요 내용
- 확장 권한: 파일 시스템, 네트워크 등 민감 자원 접근에 대한 주의 필요
- 실행 격리: 일부 환경에서는 확장을 별도 프로세스에서 실행하거나 제한된 API만 허용
- 보안 권장사항: 출처 확인, 최소 권한 원칙, 정기 업데이트, 리뷰 및 모니터링

## 실무 팁
- 신규 확장 설치 전에 소스 코드(오픈소스일 경우) 또는 퍼미션 요구사항을 검토하세요.
- 의심스러운 동작(백그라운드 네트워크 호출, 파일 변경 등)이 발견되면 즉시 비활성화하세요.
- 기업 환경에서는 확장 허용 목록(allowlist)을 만들어 검증된 확장만 사용하도록 정책을 적용하세요.

## 핵심 정리
확장은 편리하지만 실행 시 보안 리스크가 있으므로 출처 확인, 최소 권한, 모니터링 정책을 통해 위험을 관리하세요.
