# VSCode 에디터 03.09.02 음성 접근성 (Voice)

## 한줄 요약
음성 접근성 기능은 음성 합성(읽기)과 음성 입력을 통해 코드 및 UI를 음성으로 접근하거나 제어하는 방법을 안내합니다.

## 핵심 개념
- 음성 출력(텍스트 음성 변환)과 음성 입력(음성 인식)은 플랫폼의 접근성 서비스와 통합되어 작동합니다.
- VS Code 자체적으로 음성 인식 엔진을 제공하기보다 운영체제나 보조 기술(screen reader, speech-to-text)과의 호환을 지원합니다.
- 음성 관련 동작은 접근성 모드, 키보드 포커스, ARIA 속성 등에 의해 개선됩니다.

## 주요 기능
- 화면 판독기와의 연동으로 현재 포커스된 요소를 음성으로 안내받을 수 있습니다.
- 음성 입력을 활용하려면 플랫폼의 음성-텍스트 기능을 활성화하고 VS Code 편집기와 연동해 사용합니다.
- 음성 관련 설정과 로그를 통해 호환성 문제를 진단할 수 있습니다.

## 실무 팁
- 음성 기능은 운영체제와 사용 중인 보조 기술의 설정에 크게 의존하므로, 먼저 OS의 음성 옵션을 구성하세요.
- 화면 판독기(예: NVDA, VoiceOver) 사용 시 VS Code의 접근성 모드를 함께 활성화해 더 나은 경험을 얻을 수 있습니다.
- 음성 입력으로 코드 작성 시 오타·구문 오류가 발생하기 쉬우니, 음성 후에는 반드시 편집기로 검토하세요.

## 핵심 정리
VS Code는 음성 접근성을 플랫폼 보조 기술과의 통합을 통해 지원합니다. 최적의 결과를 위해 OS/보조 기술 설정을 점검하고 접근성 모드를 병행하세요.
