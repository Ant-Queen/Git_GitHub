# VSCode 에디터 03.06.02 확장 마켓플레이스 (Extension Marketplace)

## 한줄 요약
Marketplace는 VS Code 확장을 검색, 설치, 관리하는 중앙 허브입니다; 확장 평점과 다운로드 수로 품질을 판단할 수 있습니다.

## 핵심 개념
- Marketplace는 VS Code 내부의 `Extensions` 뷰나 웹(Visual Studio Marketplace)에서 접근 가능합니다.
- 확장 페이지는 설명, 사용법, 버전 기록, 기여 포인트, 이슈 링크, 소스 링크 등을 포함합니다.
- 설치, 업데이트, 비활성화, 제거 등의 관리가 가능하며, 확장 추천을 통해 프로젝트에 맞는 확장을 찾습니다.

## 주요 기능
- 확장 검색 및 필터링(인기, 평점, 최근 업데이트 등)
- 확장 페이지에서 명령, 설정, 스니펫 등 기여 항목 확인
- 개별 확장에 대한 자동 업데이트 설정 가능

## 실무 팁
- 확장 설치 전 리뷰와 README, 이슈 활동을 확인해 유지보수 상태를 점검하세요.
- 기업 환경에서는 Marketplace 접근을 제한하거나 사내 레포지토리를 통해 검증된 확장만 배포하세요.
- 확장 간 충돌이 의심되면 일괄적으로 비활성화한 뒤 필요한 확장만 활성화해 문제를 재현하세요.

## 핵심 정리
Marketplace는 확장 발견과 관리를 편리하게 해주는 포털입니다. 설치 전 문서와 유지보수 상태를 확인하면 안정적으로 확장을 활용할 수 있습니다.
