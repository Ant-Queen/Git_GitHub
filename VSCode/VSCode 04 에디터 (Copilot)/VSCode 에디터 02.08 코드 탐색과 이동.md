# VSCode 에디터 02.08 코드 탐색과 이동

## 한줄 요약
VS Code는 코드 이동과 탐색 기능이 매우 강력해서, 큰 프로젝트에서도 함수, 클래스, 심볼, 참조 위치를 빠르게 찾을 수 있습니다.

## 핵심 개념
- Go to Definition: 심볼의 정의 위치로 이동합니다.
- Peek: 정의나 참조를 편집기 안에서 미리 확인할 수 있습니다.
- Breadcrumbs: 파일 경로와 심볼 경로를 한눈에 보여줍니다.
- Go to Symbol: 현재 파일의 심볼을 빠르게 찾습니다.
- Open Symbol by Name: 프로젝트 전체의 심볼을 검색합니다.

## 자주 쓰는 기능
- F12: 정의로 이동
- Alt+F12: Peek Definition
- Shift+F12: 참조 찾기
- Ctrl+Shift+O: 파일 내 심볼 이동
- Ctrl+T: 프로젝트 전체 심볼 검색
- Ctrl+Shift+\: 괄호 짝 찾기

## 실무 팁
- 큰 코드베이스에서는 “정의로 이동”과 “참조 찾기”가 생산성을 크게 높입니다.
- Breadcrumbs는 현재 위치를 잊지 않게 해주는 좋은 네비게이션 도구입니다.
- 찾기/이동 기능을 익히면 코드 읽기 속도가 빨라집니다.

## 핵심 정리
코드 탐색 기능은 VS Code의 진짜 강점 중 하나로, 읽기와 수정 모두를 빠르게 만들어 줍니다.
