# VS Code 에이전트 개념

원문: https://code.visualstudio.com/docs/agents/concepts/agents

---

## 1. 한 줄 요약

에이전트는 사용자의 목표를 이해하고, 여러 단계를 거쳐 실제 작업을 수행하는 AI 실행 시스템입니다.

---

## 2. 에이전트가 하는 일

에이전트는 보통 다음 순환을 반복합니다.

1. 이해하기: 관련 파일과 정보를 읽음
2. 행동하기: 코드 수정, 테스트 실행, 외부 호출 등 수행
3. 검증하기: 결과를 확인하고 필요하면 다시 수정

이 흐름을 “에이전트 루프”라고 합니다.

---

## 3. 주요 개념

### 에이전트 루프
- 작업을 여러 단계로 나누고, 결과를 반영해 반복합니다.

### 에이전트 타입
- 로컬, 클라우드, 백그라운드, 서드파티 등 환경에 따라 다르게 동작합니다.

### 서브에이전트
- 복잡한 작업을 작은 단위로 나눠 맡기고, 결과만 받아와서 메인 에이전트가 정리합니다.

### 채팅 세션
- 하나의 작업 흐름을 세션 단위로 관리합니다.

### 메모리
- 이전 작업의 경험이나 프로젝트 정보를 기억해 다음 작업에 활용합니다.

### 계획
- 복잡한 작업은 먼저 계획을 세운 뒤 구현하는 방식이 더 좋습니다.

---

## 4. 왜 중요한가?

에이전트는 단순한 챗봇이 아니라, 실제 개발 작업을 수행하는 자동화 엔진에 가깝습니다.

---

## 5. 핵심 정리

에이전트는 “목표를 이해하고, 적절한 행동을 반복하며, 결과를 검증하는 AI 오퍼레이터”입니다.
