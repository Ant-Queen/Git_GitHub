# VSCode 에이전트 06.07 테스트와 Copilot

## 한줄 요약
GitHub Copilot은 테스트 프레임워크 설정, 테스트 코드 생성, 실패한 테스트 수정까지 개발자의 테스트 워크플로우를 돕습니다.

## 핵심 개념
- /setupTests 명령으로 테스트 환경을 빠르게 구성할 수 있습니다.
- Chat나 Inline Chat에서 테스트 코드를 생성할 수 있습니다.
- Editor Smart Actions로 테스트를 자동 생성할 수 있습니다.
- Test Explorer의 실패 테스트를 Copilot이 수정 제안을 제공합니다.
- 팀 규칙이 있다면 custom instructions로 테스트 스타일을 맞출 수 있습니다.

## 실무 예시
- “이 코드에 대한 유닛 테스트를 작성해줘”
- “엣지 케이스까지 포함한 통합 테스트를 생성해줘”
- “실패한 테스트 원인을 수정해줘”

## 핵심 정리
Copilot은 테스트 작성과 유지보수를 빠르게 도와주지만, 테스트의 품질과 맥락은 개발자가 검토하는 것이 중요합니다.
