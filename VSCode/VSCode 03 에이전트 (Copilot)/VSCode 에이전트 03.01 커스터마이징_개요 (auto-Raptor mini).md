# VS Code 에이전트 커스터마이제이션 개요

## 소개
Visual Studio Code에서는 AI 에이전트를 프로젝트에 맞게 커스터마이즈할 수 있는 여러 도구를 제공합니다. 이 문서는 전체 커스터마이제이션 환경과 사용할 수 있는 주요 유형을 한눈에 정리합니다.

## 주요 커스터마이제이션 유형

- **Custom Instructions**: 코딩 스타일, 아키텍처 규칙, 보안 요구사항 등 프로젝트 전반에 적용되는 지침을 정의합니다.
- **Prompt Files**: 자주 쓰는 프롬프트를 `/` 명령어로 실행할 수 있는 재사용 가능한 Markdown 파일입니다.
- **Agent Skills**: 도구, 스크립트, 예제 리소스를 함께 묶어서 특정 작업을 수행할 수 있게 하는 재사용 가능한 기능 단위입니다.
- **Custom Agents**: 특정 도메인과 역할을 위한 전용 AI 페르소나를 정의합니다. 도구 제한, 모델, 지침을 개별화할 수 있습니다.
- **Language Models**: 대화에 사용할 AI 모델을 선택하거나 직접 API 키를 등록하여 BYOK(자체 모델) 환경을 구성합니다.
- **MCP Servers**: Model Context Protocol 기반 서버를 연결하여 외부 도구, 데이터, 리소스를 AI에 통합합니다.
- **Hooks**: 에이전트 생명주기 지점에서 셸 명령을 실행하여 정책 적용, 자동화, 감사 로그 등을 구현합니다.
- **Agent Plugins**: 위의 커스터마이제이션을 하나의 설치 가능한 패키지로 묶어서 배포하고 공유합니다.

## 단계별 도입

1. **프로젝트 지침부터 시작**: `.github/copilot-instructions.md` 등의 always-on instructions로 공통 규칙을 먼저 정의합니다.
2. **파일별 규칙 추가**: 특정 폴더나 언어에 적용되는 `.instructions.md` 파일로 세부 규칙을 보강합니다.
3. **자주 쓰는 작업 자동화**: `*.prompt.md`를 만들어 반복 작업을 빠르게 실행합니다.
4. **전문화된 역할 구성**: 커스텀 에이전트로 계획, 구현, 리뷰 등의 페르소나를 분리합니다.
5. **외부 툴과 통합**: MCP 서버와 Hooks를 통해 테스트, 배포, 보안 검사 등 외부 도구와 연결합니다.

## 관리 및 발견

- **Agent Customizations editor**: Chat 보기나 Agents 창에서 커스터마이제이션을 한곳에서 탐색, 생성, 편집할 수 있습니다.
- **모노레포 지원**: `chat.useCustomizationsInParentRepositories` 설정을 사용하면 부모 저장소 루트에서 커스터마이제이션을 자동으로 검색할 수 있습니다.
- **우선순위**: 다수의 커스터마이제이션이 존재할 때 VS Code는 다양한 소스를 함께 조합하여 적용하되, 개인 수준, 리포지토리 수준, 조직 수준 순으로 우선순위를 정합니다.

## 주의 사항

- 에이전트 커스터마이제이션은 현재 일부 기능이 Preview 상태입니다.
- 조직에서 관련 정책을 통해 사용을 제한할 수 있으므로 회사 환경에서는 관리자 설정을 확인해야 합니다.
- 커스터마이제이션 파일은 신뢰할 수 있는 소스에서 관리해야 합니다. 특히 Hooks나 MCP 서버는 로컬 시스템에서 코드 실행 권한을 가질 수 있습니다.
