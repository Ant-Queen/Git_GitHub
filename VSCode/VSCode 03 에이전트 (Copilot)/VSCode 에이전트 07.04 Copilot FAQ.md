# VSCode 에이전트 07.04 Copilot FAQ

## 한줄 요약
GitHub Copilot FAQ는 구독, 계정 연결, 사용량, 채팅 기능, 에이전트 사용 가능 여부 같은 자주 묻는 문제를 정리한 문서입니다.

## 핵심 개념
- Copilot 구독은 개인, 조직, 기업 계정에 따라 다릅니다.
- GitHub 계정으로 로그인하면 더 많은 모델과 기능을 사용할 수 있습니다.
- AI 크레딧과 인라인 제안 사용량은 월 단위로 관리됩니다.
- 채팅 기능이나 에이전트 기능이 안 될 때는 계정, 구독, 네트워크, 설정 상태를 확인해야 합니다.
- 조직 관리자는 AI 기능 활성화와 모델 접근 권한을 제어할 수 있습니다.

## 실무 팁
- 구독이 인식되지 않으면 GitHub 계정 로그인 상태와 구독 상태를 확인한다.
- 사용량이 초과되면 크레딧 소모를 줄이거나 다음 월까지 기다린다.
- 네트워크/방화벽 환경이면 Copilot 연결 문제를 점검한다.

## 핵심 정리
FAQ는 Copilot을 처음 쓰거나 문제가 생겼을 때 가장 먼저 확인해야 할 실전 정보들을 모아둔 문서입니다.
