# VS Code Copilot 채팅 컨텍스트

원문: https://code.visualstudio.com/docs/chat/copilot-chat-context

---

## 1. 한 줄 요약

AI가 더 정확한 답변을 하도록, 채팅에 적절한 컨텍스트를 함께 제공하는 방법을 정리한 문서입니다.

---

## 2. 컨텍스트가 중요한 이유

AI는 질문만 보면 일반적인 답변을 내놓을 가능성이 큽니다. 하지만 코드 작업에서는 현재 파일, 선택한 코드, 프로젝트 구조, 터미널 출력 같은 정보가 매우 중요합니다.

---

## 3. 대표적인 컨텍스트 방법

### #-mentions
- 파일, 폴더, 심볼, 터미널 출력, 코드베이스 등 특정 정보를 명시적으로 넣을 수 있습니다.
- 예: #src, #README.md, #codebase

### 파일/폴더 드래그 앤 드롭
- Explorer나 에디터 탭에서 직접 채팅으로 보내기 가능

### 웹 페이지 참조
- URL을 넣거나 #fetch를 사용해 외부 정보를 가져올 수 있습니다.

### 이미지/브라우저 컨텍스트
- 화면 캡처나 브라우저 요소를 첨부해 UI 관련 질문도 가능합니다.

---

## 4. 컨텍스트 관리의 핵심

- 너무 적으면 답변이 모호해집니다.
- 너무 많으면 토큰 사용량이 늘고 요약이 필요해질 수 있습니다.
- 따라서 필요한 정보만 목적에 맞게 넣는 것이 좋습니다.

---

## 5. 컨텍스트 창 사용법

VS Code는 채팅 입력창에 컨텍스트 사용량을 표시합니다. 대화가 길어지면 자동 요약이 일어나기도 하므로, 필요 시 새 세션을 시작하는 것이 좋습니다.

---

## 6. 핵심 정리

컨텍스트는 AI에게 “어떤 상황에서 답해야 하는지”를 알려주는 핵심 정보입니다. 적절한 컨텍스트를 제공하면 답변 품질이 크게 좋아집니다.
