# VS Code AI 코드 수정 리뷰

원문: https://code.visualstudio.com/docs/chat/review-code-edits

---

## 1. 한 줄 요약

AI가 만든 코드 변경사항을 검토하고, 승인하거나 되돌릴 수 있게 해 주는 기능입니다.

---

## 2. 왜 필요한가?

AI는 빠르게 코드를 수정할 수 있지만, 그 결과가 항상 완벽하진 않습니다. 따라서 변경사항을 직접 확인하고 승인하는 과정이 필요합니다.

---

## 3. 주요 기능

### 변경사항 확인
- 수정된 파일을 diff 형태로 확인할 수 있습니다.
- 각 변경을 개별적으로 적용하거나 취소할 수 있습니다.

### 소스 제어와 연동
- 변경사항을 스테이지하면 자동으로 승인 처리할 수 있습니다.
- 변경사항을 버리면 AI가 만든 수정도 함께 제거됩니다.

### 민감 파일 보호
- 설정 파일이나 환경 변수 파일 같은 민감한 파일은 승인 절차를 거치게 할 수 있습니다.

---

## 4. 실무 팁

- 자동 승인 기능을 쓰더라도, 중요한 변경은 반드시 검토해야 합니다.
- 보안이 중요한 파일은 수동 승인으로 설정하는 것이 안전합니다.
- 팀 작업에서는 AI 수정 결과를 리뷰하고 커밋하는 흐름을 반드시 갖추는 것이 좋습니다.

---

## 5. 핵심 정리

AI가 만든 코드 변경사항은 “바로 적용”하기보다 “검토 후 승인”하는 방식이 안전합니다. VS Code는 이 과정을 편하게 해 주는 도구들을 제공합니다.
