# 세션 인사이트 정리

원문: https://code.visualstudio.com/docs/agents/sessions/session-insights

---

## 1. 한 줄 요약

세션 인사이트는 과거의 Copilot 세션 기록을 검색하고, 요약하고, 질문할 수 있게 해주는 기능입니다.

---

## 2. 무엇을 할 수 있나?

이 기능을 사용하면 다음을 할 수 있습니다.

- 최근 작업 내용을 요약해서 스탠드업 보고서처럼 보기
- 과거 세션에서 특정 파일, PR, 이슈, 키워드를 검색하기
- 자연어로 질문하기
  - 예: "어제 어떤 파일을 수정했지?"
  - 예: "결제 API와 관련된 작업이 있었나?"

---

## 3. 대표 명령어

채팅 입력창에서 다음 명령어를 사용할 수 있습니다.

- `/chronicle:standup`
  - 최근 세션을 기준으로 스탠드업 요약을 보여줍니다.
- `/chronicle:tips`
  - 실제 사용 패턴을 바탕으로 Copilot 활용 팁을 제안합니다.
- `/chronicle:cost-tips`
  - 토큰 사용량과 비용을 줄일 수 있는 방법을 분석합니다.
- `/chronicle:search <query>`
  - 키워드, 파일 경로, PR/이슈 번호로 세션을 검색합니다.
- `/chronicle:reindex`
  - 로컬 세션 인덱스를 다시 만들고 클라우드 동기화까지 다시 진행합니다.

---

## 4. 어떤 정보가 저장되나?

세션 기록에는 다음 정보가 포함됩니다.

- 세션 메타데이터: 저장소, 브랜치, 작업 디렉터리, 시간 정보
- 대화 기록: 사용자 메시지와 에이전트 응답
- 파일 변경 기록: 도구 호출로 수정한 파일 경로
- 외부 참조: PR 번호, 이슈 번호, 커밋 SHA

중요한 점은 비밀 정보(토큰, API 키, 비밀번호, 연결 문자열)는 동기화 전에 자동으로 필터링된다는 것입니다.

---

## 5. 언제 유용한가?

- 과거 작업 내용을 기억하지 못할 때
- 어떤 파일을 수정했는지 확인하고 싶을 때
- 이전 세션을 다시 이어가고 싶을 때
- 팀 회고나 작업 정리를 하고 싶을 때

---

## 6. 참고할 점

- 세션 동기화가 켜져 있으면, 여러 종류의 세션 기록을 함께 조회할 수 있습니다.
- 세션이 누락되거나 인덱스가 깨졌을 때는 재인덱싱을 하면 됩니다.

---

## 7. 핵심 정리

세션 인사이트는 "내가 지금까지 무엇을 했는지 기억해주는 검색 엔진"처럼 생각하면 됩니다.
