# VS Code 에이전트 커스터마이징 - Custom Agents

원문: https://code.visualstudio.com/docs/agent-customization/custom-agents

---

## 1. 한 줄 요약

Custom Agents는 특정 역할에 맞춰 미리 설정된 에이전트입니다. 예를 들어 리뷰어, 플래너, 구현 담당자 같은 역할을 만들 수 있습니다.

---

## 2. 왜 쓰나?

기본 에이전트는 범용적이지만, 작업마다 필요한 도구와 스타일이 다릅니다.
Custom Agents를 쓰면 다음이 가능합니다.

- 역할별로 다른 지시문 설정하기
- 필요한 도구만 제한적으로 사용하게 만들기
- 모델도 역할에 따라 다르게 지정하기
- 작업 흐름을 더 명확하게 분리하기

---

## 3. 기본 구조

Custom Agent는 `.agent.md` 파일로 정의합니다.

포함할 수 있는 요소는 다음과 같습니다.

- 설명문
- 역할 지시문
- 허용 도구 목록
- 모델 지정
- handoff(다음 단계로 넘어가는 흐름)

---

## 4. 예시 역할

- Planning Agent: 구현 전에 계획을 세우는 역할
- Review Agent: 코드 품질과 보안 관점에서 검토하는 역할
- Implementation Agent: 실제 코드 변경을 수행하는 역할

---

## 5. Handoffs

에이전트 간 이동 흐름을 연결할 수 있습니다.
예를 들어:

- 계획 에이전트 → 구현 에이전트
- 구현 에이전트 → 리뷰 에이전트

이런 식으로 작업 흐름을 단계별로 이어갈 수 있습니다.

---

## 6. 보안 관점

보안이 중요한 작업에서는 읽기 전용 도구만 허용하는 에이전트를 만드는 것이 좋습니다.
이렇게 하면 잘못된 변경을 줄일 수 있습니다.

---

## 7. 핵심 정리

Custom Agents는 “작업 역할별로 AI의 성격과 권한을 미리 설정해 두는 기능”입니다. 복잡한 워크플로를 더 깔끔하게 나누는 데 매우 유용합니다.
