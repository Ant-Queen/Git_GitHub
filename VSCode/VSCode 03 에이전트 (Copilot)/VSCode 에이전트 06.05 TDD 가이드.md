# VSCode 에이전트 06.05 TDD 가이드

## 한줄 요약
TDD 흐름을 AI와 함께 쓰면 테스트 작성 → 구현 → 리팩터링 단계를 자동화하면서 품질과 속도를 동시에 높일 수 있습니다.

## 핵심 개념
- Red: 먼저 실패하는 테스트를 작성한다.
- Green: 테스트를 통과하는 최소 구현을 만든다.
- Refactor: 테스트가 유지되는 범위에서 구조를 개선한다.
- 커스텀 에이전트와 핸드오프를 쓰면 각 단계의 역할을 분리할 수 있다.
- testing.instructions.md로 테스트 기준을 미리 정해두면 AI의 테스트 품질이 좋아진다.

## 실무 방법
- 테스트 규칙을 문서화한다.
- Red/Green/Refactor용 에이전트를 분리한다.
- 각 단계에서 실행 결과를 확인한 뒤 다음 단계로 넘어간다.

## 흔한 실수
- 테스트 없이 구현을 바로 시작하는 것
- 구현 세부사항까지 검증하는 테스트 작성
- 한 번에 너무 많은 기능을 넣는 것

## 핵심 정리
TDD는 “테스트가 요구사항을 정의하게 만드는 방법”이며, AI와 결합하면 반복적이고 안정적인 개발 사이클이 됩니다.
