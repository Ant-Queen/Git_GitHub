# VS Code 에이전트 커스터마이징 - Prompt Files

원문: https://code.visualstudio.com/docs/agent-customization/prompt-files

---

## 1. 한 줄 요약

Prompt Files는 자주 쓰는 작업을 재사용 가능한 프롬프트로 저장해 두고, `/명령어`처럼 바로 실행할 수 있게 해 주는 기능입니다.

---

## 2. 왜 쓰나?

반복적인 작업을 매번 새로 입력하는 대신, 다음과 같이 저장해 두고 재사용할 수 있습니다.

- 컴포넌트 생성
- 테스트 작성
- 보안 리뷰
- PR 준비
- 코드 설명

---

## 3. 기본 구조

Prompt File은 `.prompt.md` 파일로 저장합니다.

내용은 보통 다음으로 구성됩니다.

- 프롬프트 설명
- 실행할 지시문
- 필요한 도구나 에이전트 설정
- 입력 변수나 예시

---

## 4. 사용 방식

- 채팅 입력창에서 `/프롬프트이름` 형태로 실행할 수 있습니다.
- Command Palette에서 선택해서 실행할 수도 있습니다.
- 에디터에서 실행 버튼을 눌러 바로 테스트할 수도 있습니다.

---

## 5. 장점

- 자주 쓰는 작업을 단축할 수 있습니다.
- 팀 공통 워크플로를 표준화하기 좋습니다.
- 프롬프트의 가독성과 재사용성이 높아집니다.

---

## 6. 실무 팁

- 프롬프트는 한 작업에 집중하게 작성하는 것이 좋습니다.
- 기대 결과를 명확히 적으면 AI가 더 안정적으로 동작합니다.
- 반복해서 쓰는 규칙은 Custom Instructions와 연결하면 더 좋습니다.

---

## 7. 핵심 정리

Prompt Files는 “자주 쓰는 작업을 저장해 둔 재사용형 명령”입니다. 반복 업무를 줄이고, 팀의 작업 표준화를 쉽게 만들 수 있습니다.

---
