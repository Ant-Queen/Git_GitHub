# Copilot CLI 에이전트 정리

원문: https://code.visualstudio.com/docs/agents/agent-types/copilot-cli

---

## 1. 한 줄 요약

Copilot CLI 에이전트는 VS Code에서 백그라운드로 실행되는 자동화형 에이전트입니다. 로컬 머신에서 독립적으로 작업을 진행하면서, 사용자는 다른 일을 계속할 수 있습니다.

---

## 2. 이런 경우에 좋다

- 즉각적인 상호작용이 필요하지 않은 작업
- 구현 범위가 비교적 분명한 작업
- 기능 구현, 수정, 여러 실험 실행 같은 작업
- 장시간 실행해도 괜찮은 작업

---

## 3. 핵심 특징

- 백그라운드에서 실행됩니다.
- VS Code 창을 닫아도 작업이 이어질 수 있습니다.
- 세션은 Chat view에서 관리할 수 있습니다.
- 여러 세션을 병렬로 실행할 수 있습니다.

---

## 4. 격리 모드

Copilot CLI는 작업 변경사항을 어떻게 적용할지에 따라 두 가지 모드를 지원합니다.

### Worktree isolation

- 별도의 Git worktree에서 작업합니다.
- 메인 워크스페이스와 분리되어 안전합니다.
- 리뷰 후 적용할 때 편합니다.

### Folder isolation

- 현재 워크스페이스에 직접 변경합니다.
- 변경사항이 바로 반영됩니다.

---

## 5. 권한과 승인

- Worktree 모드에서는 대부분 자동 승인됩니다.
- Folder 모드에서는 기본 승인, 우회 승인, 자동 실행 등 세 수준을 선택할 수 있습니다.

---

## 6. 시작하는 방법

1. Chat view에서 새 세션을 만듭니다.
2. 세션 타깃으로 Copilot CLI를 선택합니다.
3. 작업을 설명하는 프롬프트를 입력합니다.
4. 세션 상태를 Chat view에서 추적합니다.

---

## 7. 로컬 세션에서 넘기는 방법

복잡한 작업은 먼저 로컬 에이전트로 정리한 뒤, Copilot CLI로 넘길 수 있습니다.

- 로컬 세션에서 계획을 세운 뒤 구현을 백그라운드로 넘길 수 있습니다.
- 대화 기록과 맥락이 함께 전달됩니다.

---

## 8. 추가 기능

- 원격 제어 기능으로 GitHub나 모바일에서도 세션을 모니터링할 수 있습니다.
- 터미널에서도 Copilot CLI를 직접 사용할 수 있습니다.
- 커스텀 에이전트와도 연동할 수 있습니다.
- `/research` 같은 고급 명령도 지원합니다.

---

## 9. 한계점

- VS Code의 모든 내장 도구를 쓸 수 있는 것은 아닙니다.
- 확장 제공 도구나 일부 MCP 서버 제한이 있을 수 있습니다.

---

## 10. 핵심 정리

Copilot CLI는 "바로바로 답변하는 대신, 백그라운드에서 길게 작업해주는 에이전트"로 이해하면 됩니다.
