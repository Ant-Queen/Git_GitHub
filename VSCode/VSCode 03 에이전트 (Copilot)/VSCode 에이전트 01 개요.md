# VS Code 에이전트 네이티브 개요

Visual Studio Code는 AI 에이전트를 기본으로 탑재하여, 사용자가 원하는 작업을 설명하면 에이전트가 프로젝트 전체를 분석하고 코드 작성, 디버깅, 테스트, 리팩터링, 팀 협업까지 지원합니다.

## 1. 작업 방식 선택

VS Code에는 두 가지 에이전트 환경이 있습니다.

- 에이전트 우선(Agent-first): 채팅이 기본 인터페이스인 에이전트 중심 환경으로, 여러 프로젝트를 가로질러 에이전트를 조율합니다.
- 코드 우선(Code-first): 편집기, 디버거, 확장과 함께 에이전트가 보조 역할을 수행합니다.
- 언제든지 전환 가능: 두 환경 모두 동일한 에이전트 세션, 설정, 키바인딩을 공유하므로 자유롭게 이동할 수 있습니다.

## 2. 어떤 모델이든 실행

에이전트는 작업 위치에 따라 실행됩니다.

- 로컬: 대화형 작업에 적합
- 백그라운드: 자율 작업에 적합
- 클라우드: 풀 리퀘스트 기반 팀 협업에 적합
- 서드파티 제공자: Anthropic, OpenAI 등 외부 모델 사용 가능

특징:

- 여러 모델을 자유롭게 선택
- 필요한 경우 API 키를 직접 가져와 원하는 모델을 사용할 수 있음
- 에이전트 유형 간 전환 시 컨텍스트 유지

## 3. 에이전트를 나만의 방식으로 구성

에이전트가 프로젝트 관습과 규칙을 이해하도록 여러 맞춤형 옵션을 제공합니다.

- 맞춤 지침(Custom instructions): 코딩 스타일과 규칙을 정의하여 에이전트가 팀 스타일에 맞는 코드를 생성하도록 함
- 맞춤 에이전트(Custom agents): 코드 리뷰어, 문서 작성자 등 특정 역할을 수행하는 에이전트 생성
- 에이전트 스킬(Agent skills): VS Code, CLI, 클라우드 에이전트 전반에 걸쳐 특화된 기능을 가르침
- MCP 서버(MCP servers): 외부 도구와 서비스에 연결하여 데이터베이스, API 등 추가 리소스 접근 허용

## 4. 신뢰와 제어

에이전트는 파일 읽기/쓰기, 터미널 명령 실행, 외부 서비스 호출이 가능합니다. VS Code는 다음과 같이 사용자를 보호합니다.

- 도구 호출 실행 전에 승인 또는 거부
- 허용 수준에 따라 에이전트 자율성 제어
- 에이전트 샌드박싱으로 파일 시스템 및 네트워크 접근 제한

조직용 기능:

- AI 기능, 모델, 도구를 중앙에서 관리
- 정책으로 에이전트 기능, MCP 서버, 확장 사용 제한
- 규정 준수와 일관된 팀 경험 제공

## 5. 시작하기

AI 기능을 사용하려면 GitHub 계정으로 로그인해야 합니다.

1. 상태 표시줄의 Copilot 아이콘 위에 마우스를 올리고 `Use AI Features` 선택
2. 안내에 따라 로그인
3. 구독이 없으면 무료 요금제로 등록되며 제안 및 채팅에 월별 제한이 적용됨

팁:

- Copilot 구독 없이도 API 키를 직접 사용해 원하는 모델을 연결할 수 있음
