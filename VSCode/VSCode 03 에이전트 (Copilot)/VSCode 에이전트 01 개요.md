# VS Code 에이전트 개요

원문: https://code.visualstudio.com/docs/agents/overview

---

## 1. 한 줄 요약

VS Code의 에이전트는 자연어로 작업을 설명하면, 코드 수정·파일 생성·명령 실행·테스트 확인까지 자동으로 처리해주는 기능입니다.

즉, "이 기능을 추가해줘"라고 말하면 에이전트가 계획을 세우고, 실제로 코드를 바꾸고, 필요하면 실행까지 해주는 방식입니다.

---

## 2. 에이전트가 할 수 있는 일

에이전트는 다음과 같은 작업에 강합니다.

- 구현 계획 세우기
  - 먼저 어떤 순서로 작업할지 계획을 짭니다.
- 새 기능 추가
  - UI, 상태 관리, 테스트까지 함께 구성해줍니다.
- 빠른 프로토타입 만들기
  - 여러 아이디어를 빠르게 시험해볼 수 있습니다.
- 리팩터링
  - 파일 구조나 이름을 대규모로 바꾸는 작업도 이어서 처리합니다.
- 웹 앱 확인
  - 실행 중인 앱을 통해 실제 동작을 확인할 수 있습니다.
- 디버깅
  - 오류 로그나 실패한 테스트를 보고 원인을 찾고 수정합니다.

---

## 3. 어떻게 시작하나?

VS Code에서 에이전트를 사용하려면 다음 순서로 진행하면 됩니다.

1. GitHub 계정으로 로그인합니다.
2. VS Code에서 AI 기능을 활성화합니다.
3. 에이전트 창을 열거나 채팅 화면을 사용합니다.
4. 원하는 작업을 자연어로 입력합니다.

예시:

- "헤더에 다크 모드 토글을 추가해줘"
- "모바일 화면에서도 잘 작동하도록 수정해줘"

> 참고: 조직 정책에 따라 에이전트 기능이 제한될 수 있습니다.

---

## 4. 에이전트와 작업하는 두 가지 방식

VS Code에는 두 가지 주요 작업 방식이 있습니다.

### 4-1. Agents window

- 에이전트 중심으로 작업하는 화면입니다.
- 여러 작업을 동시에 관리하기 좋습니다.
- 여러 프로젝트를 넘나드는 고수준 작업에 적합합니다.

### 4-2. Chat view

- 코드 중심으로 작업하는 화면입니다.
- 현재 열린 작업공간 안에서 코드를 직접 다루기 좋습니다.
- 구현 작업을 코드와 함께 확인하면서 진행할 때 적합합니다.

둘은 같은 세션을 공유하므로, 한쪽에서 시작한 작업을 다른 쪽에서 이어갈 수 있습니다.

---

## 5. 세션 설정하는 방법

에이전트 세션을 시작할 때 아래 요소를 설정할 수 있습니다.

- 에이전트 유형
  - 로컬에서 실행되는지, CLI로 실행되는지, 클라우드에서 실행되는지 선택합니다.
- 에이전트 종류
  - 기본 에이전트, 계획형 에이전트, 질문형 에이전트 등 역할에 따라 선택합니다.
- 언어 모델
  - 빠른 처리용 모델과 복잡한 추론용 모델 중 선택합니다.
- 권한 수준
  - 모든 동작을 승인받을지, 일부는 자동으로 진행할지 결정합니다.

---

## 6. 프로젝트에 맞게 에이전트를 조정하는 방법

에이전트는 단순히 코드를 작성하는 도구가 아니라, 팀의 규칙에 맞게 동작하도록 맞춤화할 수 있습니다.

### 가능한 맞춤화

- 코드 스타일 규칙 설정
  - 프로젝트 규칙을 정해두면 에이전트가 그 방식대로 작성합니다.
- 반복 작업 자동화
  - 자주 쓰는 작업 흐름이나 템플릿을 저장해 재사용합니다.
- 전용 에이전트 만들기
  - 보안 전문가, 문서 작성자, 테스터 같은 역할 기반 에이전트를 만들 수 있습니다.
- 외부 도구 연결
  - 데이터베이스나 API 같은 외부 서비스와 연결할 수 있습니다.

---

## 7. 신뢰와 제어

에이전트는 파일 수정, 터미널 명령 실행, 외부 서비스 호출까지 할 수 있습니다.

그래서 VS Code는 다음과 같은 방식으로 사용자가 제어할 수 있게 설계되어 있습니다.

- 실행 전 승인받기
- 권한 수준 조절
- 파일 시스템이나 네트워크 접근 제한

즉, 자동화의 편리함과 안전성을 함께 잡아주는 구조입니다.

---

## 8. 조직 차원에서의 관리

기업 환경에서는 관리자가 다음을 통제할 수 있습니다.

- 어떤 AI 기능을 사용할 수 있는지
- 어떤 모델을 사용할 수 있는지
- 어떤 도구나 확장 기능을 허용할지

이렇게 하면 팀 전체가 일관된 방식으로 AI 도구를 쓸 수 있습니다.

---

## 9. 핵심 정리

VS Code의 에이전트는 다음 3가지를 중심으로 이해하면 쉽습니다.

1. 자연어로 목표를 말하면 작업을 대신 수행해준다.
2. 코드 수정, 실행, 테스트까지 이어서 처리한다.
3. 사용자가 승인하고 제어할 수 있는 범위 안에서 안전하게 사용할 수 있다.
