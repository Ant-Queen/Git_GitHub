# VS Code 채팅 개요

원문: https://code.visualstudio.com/docs/chat/chat-overview

---

## 1. 한 줄 요약

VS Code의 채팅 기능은 코드 작업을 자연어로 수행하게 해 주는 AI 대화 인터페이스입니다.

---

## 2. 어떤 기능이 있나?

VS Code에는 다음과 같은 채팅 방식이 있습니다.

- 채팅 보기(Chat view): 코드 작업을 중심으로 긴 대화와 작업 수행에 적합
- 에이전트 창(Agents window): 여러 작업을 더 구조적으로 관리하는 화면
- 인라인 채팅(Inline chat): 현재 열려 있는 파일 안에서 바로 수정
- 퀵 채팅(Quick Chat): 빠르게 질문하고 답변받는 가벼운 인터페이스

---

## 3. 채팅을 잘 쓰는 기본 원칙

- 구체적으로 요청하기
- 관련 파일이나 코드 컨텍스트를 함께 주기
- 반복 작업은 slash command나 프롬프트 파일로 재사용하기
- 긴 작업은 세션을 나누어 관리하기

---

## 4. 핵심 포인트

- AI에게 “무엇을 바꿀지”를 명확히 말해야 결과가 좋아집니다.
- 채팅은 단순 질문뿐 아니라 코드 수정, 테스트, 리팩터링, 설명까지 지원합니다.
- VS Code는 작업 흐름에 따라 채팅 경험을 바꿔가며 사용할 수 있습니다.

---

## 5. 핵심 정리

VS Code의 채팅 기능은 “코드 작업을 대화형으로 처리하는 인터페이스”입니다. 작업의 성격에 맞게 채팅 보기, 에이전트 창, 인라인 채팅을 선택하면 효율적으로 쓸 수 있습니다.
