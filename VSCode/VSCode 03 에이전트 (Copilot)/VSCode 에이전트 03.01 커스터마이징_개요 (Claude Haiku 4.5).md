# VS Code 에이전트 커스터마이징 개요

## 개요

VS Code는 여러 가지 방식으로 AI에게 당신의 코드베이스, 코딩 표준, 워크플로우를 학습시킬 수 있는 기능들을 제공합니다. 이 문서는 커스터마이징 옵션들을 소개하고 시작하는 방법을 안내합니다.

## 커스터마이징 타입

### 1. **커스텀 지시사항 (Custom Instructions)**
- **목적**: 코딩 표준, 규칙, 프로젝트 구조를 정의합니다
- **사용 시기**: 프로젝트 전체에 적용되는 코딩 컨벤션이 필요할 때
- **파일**: `.github/copilot-instructions.md`, `*.instructions.md`

### 2. **프롬프트 파일 (Prompt Files)**
- **목적**: 재사용 가능한 프롬프트를 슬래시 명령으로 저장합니다
- **사용 시기**: 반복적인 작업(테스트 생성, 컴포넌트 스캐폴딩 등)을 자동화하고 싶을 때
- **파일**: `*.prompt.md`

### 3. **에이전트 스킬 (Agent Skills)**
- **목적**: 멀티 스텝 워크플로우, 스크립트, 리소스를 패키징합니다
- **사용 시기**: 여러 도구와 리소스가 필요한 특화된 기능을 제공하고 싶을 때
- **파일**: `SKILL.md`
- **특징**: 오픈 표준으로 여러 AI 도구(VS Code, Copilot CLI, Copilot Cloud Agent)에서 사용 가능

### 4. **커스텀 에이전트 (Custom Agents)**
- **목적**: 특정 역할을 위해 특화된 AI 페르소나를 정의합니다
- **사용 시기**: 서로 다른 도구 접근권한, 지시사항, 모델이 필요한 여러 역할을 다루고 싶을 때
- **파일**: `*.agent.md`
- **특징**: 핸드오프(다른 에이전트로의 전환)를 지원합니다

### 5. **언어 모델 (Language Models)**
- **목적**: 요청을 처리할 AI 모델을 선택합니다
- **사용 시기**: 특정 모델을 사용하거나 자신의 API 키를 가져오고 싶을 때
- **특징**: 빠른 모델과 추론 모델 중 선택 가능

### 6. **MCP 서버 (MCP Servers)**
- **목적**: Model Context Protocol을 통해 외부 도구와 서비스를 연결합니다
- **사용 시기**: 데이터베이스, API, 파일 시스템 등 외부 리소스에 접근이 필요할 때
- **파일**: `mcp.json`

### 7. **훅 (Hooks)**
- **목적**: 에이전트 세션의 특정 라이프사이클 지점에서 커스텀 셸 명령을 실행합니다
- **사용 시기**: 보안 정책 강제, 코드 품질 자동화, 감사 추적이 필요할 때
- **파일**: `.github/hooks/*.json`

### 8. **에이전트 플러그인 (Agent Plugins)**
- **목적**: 위의 커스터마이징들을 하나의 설치 가능한 패키지로 번들합니다
- **사용 시기**: 팀이나 커뮤니티와 커스터마이징을 공유하고 싶을 때
- **파일**: `plugin.json`

## 단계별 시작하기

커스터마이징을 점진적으로 적용하세요:

### 1단계: 프로젝트 지시사항 설정
```
/init 명령을 사용하여 .github/copilot-instructions.md 파일을 자동 생성
```

### 2단계: 대상화된 지시사항 추가
```
언어, 프레임워크, 폴더별로 *.instructions.md 파일 생성
```

### 3단계: 반복적인 작업 자동화
```
프롬프트 파일을 생성하여 일반적인 워크플로우 자동화
```

### 4단계: 특정 역할을 위한 AI 특화
```
커스텀 에이전트를 생성하여 특정 역할을 위한 전문화된 AI 페르소나 정의
```

### 5단계: 외부 도구 및 데이터 연결
```
MCP 서버와 훅을 추가하여 AI를 외부 서비스로 확장
```

## 에이전트 커스터마이징 에디터

VS Code는 **에이전트 커스터마이징 에디터**를 제공합니다. 이는 한 곳에서 모든 커스터마이징을 생성하고 관리할 수 있는 중앙 UI입니다.

**열기 방법:**
- 명령 팔레트에서 `Chat: Open Customizations` 실행
- 챗 뷰에서 설정(기어) 아이콘 선택

**기능:**
- 다양한 커스터마이징 타입별 탭 제공
- 신택스 하이라이팅과 검증을 지원하는 내장 코드 에디터
- AI를 사용한 커스터마이징 생성
- MCP 서버 및 에이전트 플러그인 마켓플레이스 브라우징

## 모노레포에서의 커스터마이징

모노레포에서 작업할 때, VS Code는 기본적으로 열린 워크스페이스 폴더 내의 커스터마이징만 발견합니다.

**해결책:** `chat.useCustomizationsInParentRepositories` 설정을 활성화하면, VS Code가 부모 저장소에서도 커스터마이징을 발견합니다.

## 커스터마이징 우선순위

여러 유형의 커스텀 지시사항이 있을 때:

1. **개인 지시사항** (사용자 레벨, 최우선)
2. **저장소 지시사항** (`.github/copilot-instructions.md` 또는 `AGENTS.md`)
3. **조직 지시사항** (최하순)

## 커스터마이징 문제 해결

커스터마이징이 제대로 적용되지 않으면:

1. 명령 팔레트에서 `Developer: Open Agent Debug Panel` 실행
2. 또는 챗 뷰의 메뉴(...)에서 `Show Agent Debug Logs` 선택

## 주요 포인트

- **점진적 적용**: 프로젝트 지시사항부터 시작하여 필요에 따라 더 추가
- **AI로 생성**: `/create-instruction`, `/create-prompt`, `/create-skill`, `/create-agent`, `/create-hook` 명령으로 AI가 커스터마이징 초안 생성
- **공유 가능**: 팀과 워크스페이스 레벨 커스터마이징 공유 가능
- **모니터링**: 에이전트 디버그 로그를 통해 커스터마이징 적용 여부 확인
