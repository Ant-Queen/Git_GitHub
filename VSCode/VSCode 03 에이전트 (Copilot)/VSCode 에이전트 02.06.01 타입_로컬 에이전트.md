# 로컬 에이전트 정리

원문: https://code.visualstudio.com/docs/agents/agent-types/local-agents

---

## 1. 한 줄 요약

로컬 에이전트는 사용자의 로컬 VS Code 환경 안에서 직접 실행되는 에이전트입니다. 현재 작업 중인 워크스페이스와 가장 가까운 맥락에서 동작합니다.

---

## 2. 언제 쓰나?

로컬 에이전트가 특히 잘 맞는 상황은 다음과 같습니다.

- 즉각적인 피드백이 필요한 작업
- 현재 개발 환경의 에러, 테스트 결과, lint 결과가 필요한 작업
- 워크스페이스 내부 맥락이 중요한 작업
- 확장 기능이나 MCP 서버가 제공하는 도구를 활용하고 싶은 작업

---

## 3. 핵심 특징

- VS Code 안에서 로컬로 실행됩니다.
- 현재 워크스페이스를 기준으로 동작합니다.
- 파일, 도구, 확장 기능, MCP 서버에 접근할 수 있습니다.
- BYOK 모델이나 다른 제공자 모델도 사용할 수 있습니다.

---

## 4. 기본 제공 에이전트

로컬 에이전트에는 세 가지 기본 유형이 있습니다.

### Agent

- 복잡한 코딩 작업에 적합합니다.
- 여러 파일을 수정하고, 도구를 실행하며, 문제를 스스로 해결합니다.

### Plan

- 구현 전 계획을 세우는 데 적합합니다.
- 복잡한 기능을 작은 단계로 나눠서 구조화합니다.

### Ask

- 코드베이스에 대한 질문에 답하거나 개념을 설명하는 데 적합합니다.
- 바로 코드를 수정하기보다 탐색과 설명에 강합니다.

---

## 5. 시작하는 방법

1. Chat view에서 에이전트 선택기에서 Agent를 선택합니다.
2. 원하는 작업을 자연어로 입력합니다.
3. 필요하면 도구를 활성화합니다.
4. 에이전트가 수정한 내용을 검토하고 승인/취소합니다.

예시 프롬프트:

- "OAuth2와 JWT를 이용한 인증 시스템을 구현해줘"
- "이 프로젝트에 CI/CD 파이프라인을 설정해줘"

---

## 6. 중요한 포인트

- 로컬 에이전트는 워크스페이스와 가장 밀접하게 연동됩니다.
- 세션이 끝나도 로컬 세션은 계속 추적할 수 있습니다.
- 민감한 파일은 실수로 수정되지 않도록 보호 기능이 있습니다.

---

## 7. 핵심 정리

로컬 에이전트는 "내 현재 작업공간에서 바로 코딩을 도와주는 에이전트"라고 생각하면 됩니다.
