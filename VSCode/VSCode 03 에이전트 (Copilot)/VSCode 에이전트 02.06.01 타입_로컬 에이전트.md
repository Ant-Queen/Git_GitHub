# 로컬 에이전트 (Local Agents)

Visual Studio Code의 로컬 에이전트는 사용자의 컴퓨터에서 직접 실행되며 현재 워크스페이스에 액세스합니다. 로컬 에이전트는 대화형 채팅 기반 인터페이스를 통해 실시간 피드백과 반복 작업을 제공하며, VS Code 확장 또는 MCP 서버가 제공하는 도구와 모델을 모두 사용할 수 있습니다.

## 왜 로컬 에이전트를 사용하나요?

- 브레인스토밍, 계획 수립, 정의되지 않은 작업처럼 즉각적인 피드백이 필요한 인터랙티브한 대화
- 린트 오류, 스택 트레이스, 단위 테스트 결과와 같은 개발 환경의 컨텍스트가 필요한 작업
- VS Code 확장 또는 MCP 서버의 특정 도구 접근이 필요한 작업
- BYOK 모델과 같은 특정 모델을 사용해야 하는 작업
- 다른 팀원의 협업이 필요 없는 개인 작업

## 주요 특징

- VS Code에서 로컬 머신 위에서 실행되고 현재 워크스페이스와 연동됩니다.
- 실시간 피드백과 반복 작업을 위한 채팅 기반 인터페이스를 사용합니다.
- 워크스페이스, 파일, 컨텍스트에 대한 전체 액세스가 가능합니다.
- 기본 제공 도구, MCP 도구, 확장 제공 도구 등 VS Code에 구성된 모든 에이전트 도구에 액세스할 수 있습니다.
- BYOK 모델과 다른 공급자의 모델을 포함해 VS Code에서 사용 가능한 모든 모델을 사용할 수 있습니다.

## 기본 제공 에이전트

로컬 에이전트 세션은 서로 다른 작업 유형에 최적화된 세 가지 기본 에이전트 중 하나를 사용합니다. 채팅 세션 중 언제든지 에이전트 선택기에서 에이전트를 전환할 수 있습니다.

### Agent

- 복잡한 코딩 작업에 최적화되어 있습니다.
- 터미널 명령 및 도구 실행이 필요할 수 있는 고수준 요구사항을 처리합니다.
- AI가 관련 컨텍스트와 파일을 결정하고, 필요한 작업을 계획하며, 문제를 해결하기 위해 반복 작업을 수행합니다.
- VS Code는 편집기에서 코드 변경을 직접 적용하며, 제안된 편집 내용을 검토할 수 있는 오버레이 컨트롤을 제공합니다.
- 여러 도구를 호출하여 작업을 완료할 수 있습니다.

### Plan

- 복잡한 기능이나 변경 사항을 작고 관리 가능한 단계로 나누는 데 최적화되어 있습니다.
- 구현 계획을 생성하고 필요한 단계를 자세히 설명합니다.
- 작업을 더 잘 이해하기 위해 명확화 질문을 제시합니다.
- 생성된 계획은 구현 에이전트에 전달하거나 가이드로 사용할 수 있습니다.

### Ask

- 코드베이스, 코딩, 일반 기술 개념에 대한 질문에 답하는 데 적합합니다.
- 코드베이스를 조사하고 관련 컨텍스트를 수집하는 능력을 사용합니다.
- 응답에 코드 블록이 포함될 수 있으며, 코드 블록 위에 마우스를 올려 "Apply in Editor" 버튼으로 적용할 수 있습니다.

### Edit 모드 (사용 중단)

- Edit 모드는 더 이상 권장되지 않습니다.
- 다중 파일 코드 편집에는 Agent 모드를 사용하세요.
- 필요하면 `chat.editMode.hidden` 설정을 활성화하여 복원할 수 있습니다.

## 시작하기

1. 채팅 보기에서 에이전트 선택기에서 `Agent`를 선택합니다.
2. 채팅 입력 필드에 고수준 프롬프트를 입력합니다.
   - 예: `OAuth2와 JWT를 사용한 사용자 인증 시스템을 구현해 주세요.`
   - 예: `이 프로젝트에 대한 CI/CD 파이프라인을 설정해 주세요.`
3. 도구 선택기를 사용해 도구를 활성화하고 에이전트의 기능을 확장합니다.
4. `Send`를 선택하거나 `Enter`를 눌러 프롬프트를 전송합니다.
5. 에이전트가 작업을 수행하는 동안 코드 변경 및 도구 호출을 검토하고 확인합니다.

## 참고

- 채팅 세션을 닫아도 로컬 에이전트는 계속 활성 상태로 유지되며 세션 보기에서 추적할 수 있습니다.
- 에이전트 옵션이 보이지 않으면, 에이전트가 활성화되어 있는지 확인하고 조직에서 비활성화되어 있는지 관리자에게 문의하세요.
- 보다 전문화된 워크플로우가 필요한 경우 [사용자 지정 에이전트](https://code.visualstudio.com/docs/agent-customization/custom-agents)를 만들 수 있습니다.

## 자주 묻는 질문

- 언어 모델이 내 컴퓨터에서 로컬로 실행되나요?
  - 로컬 에이전트는 VS Code 내에서 실행되지만, 사용하는 모델은 설정된 모델과 환경에 따라 다를 수 있습니다.
