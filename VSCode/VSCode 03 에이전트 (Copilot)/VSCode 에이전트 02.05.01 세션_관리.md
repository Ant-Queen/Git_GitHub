# VS Code 에이전트 채팅 세션 관리

VS Code의 채팅 세션은 AI와 나누는 하나의 대화를 의미합니다. 각 세션은 프롬프트, 응답, 컨텍스트를 포함하며 서로 독립적입니다.

## 1. 채팅 세션이란?

- 세션은 AI와의 하나의 대화 기록입니다.
- 한 세션에서 쌓인 컨텍스트는 새 세션으로 이어지지 않습니다.
- 새 세션을 만들면 이전 기록은 초기화되고 새로운 컨텍스트 창이 열립니다.
- 여러 세션을 병렬로 실행하여 작업별로 나눌 수 있습니다.

핵심 개념:

- 컨텍스트 창: 대화가 진행될수록 세션에 컨텍스트가 쌓입니다.
- 체크포인트: 이전 상태로 되돌리거나 이전 프롬프트를 편집해 방향을 바꿀 수 있습니다.
- 에이전트 유형: 로컬, 백그라운드, 클라우드에서 실행할 수 있습니다.
- 세션 인사이트: 세션 기록을 조회해 스탠드업 보고서, 팁 생성, 과거 작업 검색 등을 할 수 있습니다.

## 2. 새 채팅 세션 시작

새 세션을 시작하면 AI와 새로운 대화를 시작합니다.

1. 채팅 뷰에서 `New Chat (+)` 버튼을 누르거나 `Ctrl+N` 사용
2. `Agent Target` 드롭다운에서 에이전트 실행 위치 선택
   - 예: 로컬을 선택해 워크스페이스, 도구, 모델에 접근
3. `Agent` 드롭다운에서 에이전트 유형 선택
   - 예: `Plan`을 선택하면 구현 전 구조화된 계획 생성
4. 필요 시 권한 수준을 선택
5. 프롬프트 작성 후 `Enter`

## 3. 채팅 세션 열 위치

채팅 세션은 다양한 뷰에서 열 수 있습니다.

- 사이드바(기본): 코드 옆에 채팅을 표시
- 에디터 탭: 채팅을 더 넓게 보여주거나 세션을 나란히 비교
- 별도 창: 멀티 모니터 환경에서 활용
- 최대화: 채팅 패널을 에디터 전체 영역으로 확장
- Agents 창: 에이전트 우선 워크플로를 위해 전용 창 사용

세션은 언제든 다른 뷰로 이동할 수 있습니다. Chat view, 에디터 탭, 창의 `...` 메뉴에서 `Move Chat into...`을 선택하거나 명령 팔레트의 이동 명령 사용.

## 4. 세션 목록

세션 목록은 현재 워크스페이스의 모든 세션을 한 곳에서 관리합니다.

- 세션 상태, 유형, 파일 변경 정보를 확인
- 찾기 및 필터 기능으로 특정 세션 검색
- 세션을 고정(pin)하여 상단에 유지
- 워크스페이스가 없으면 모든 워크스페이스의 세션 표시
- 세션은 시간 필터(오늘, 지난주 등)로 그룹화

우클릭 메뉴를 통해 세부 정보 보기, 아카이브, 삭제, 풀 리퀘스트 체크아웃 등 작업 수행.

### 세션 상태 표시기(실험 기능)

- 미확인 세션 배지: 새 메시지가 있는 세션 수 표시
- 진행 중 세션 배지: 실행 중인 세션 수 표시
- 스파클 아이콘: 채팅 및 세션 관리 단축 열기
- `chat.agentsControl.enabled` 설정으로 표시기 켜기/끄기 가능

### 환영 페이지의 세션 보기

- 환영 페이지를 시작 화면으로 구성하면 최근 세션 바로 가기, 임베디드 채팅 위젯, 공통 작업 빠른 액션을 사용할 수 있습니다.
- `workbench.startupEditor`를 `agentSessionsWelcomePage`로 설정

## 5. 세션 보관

활성 목록을 정리하려면 완료된 세션을 보관합니다.

- 보관해도 삭제되지 않으며 활성 세션 목록에서 숨김
- 세션 위에 마우스를 올리고 `Archive` 선택
- 보관된 세션은 필터 옵션에서 `Archived` 선택해 다시 보기 가능

## 6. 세션 삭제

- 세션을 완전히 삭제하려면 목록에서 우클릭 후 `Delete` 선택
- 삭제는 되돌릴 수 없음
- Copilot CLI 세션의 경우 관련 워크트리가 함께 제거됨
- 동일 워크트리를 공유하는 다른 세션이 있을 때는 마지막 링크된 세션 삭제 시에만 워크트리 제거

> 주의: 단순히 숨기고 싶다면 먼저 보관을 고려합니다.

## 7. 요청이 실행되는 동안 메시지 보내기

요청이 진행 중일 때도 새 메시지를 보낼 수 있습니다.

- Send 버튼이 드롭다운으로 변경됨
- 선택 옵션:
  - `Add to Queue`: 현재 응답이 끝난 뒤 새 메시지 전송
  - `Steer with Message`: 현재 도구 실행이 끝난 후 새 메시지로 전환
  - `Stop and Send`: 현재 요청 취소 후 즉시 새 메시지 전송

기본 동작은 `chat.requestQueuing.defaultAction` 설정으로 조정 가능 (`steer` 또는 `queue`).

### 대기 중인 메시지 순서 변경

- 동일 유형의 대기 메시지가 여러 개 있을 때 끌어다 놓아 순서 변경
- 메시지 왼쪽에 드래그 핸들이 표시됨

## 8. 채팅 세션 포크

세션을 포크하면 현재 대화 기록을 복사한 새 독립 세션을 만듭니다.

- 포크된 세션은 원본과 완전히 분리됨
- 새 세션 제목은 `Forked:`로 시작
- Copilot CLI worktree isolation 세션은 동일한 worktree 계속 사용

포크 사용 시기:
- 다른 접근법을 시도할 때
- 사이드 질문을 던질 때
- 긴 대화를 다른 방향으로 분기하고 싶을 때

포크 방법:
- `/fork` 입력 후 Enter
- 체크포인트에서 포크: 요청 위에 마우스를 올리고 `Fork Conversation` 선택

## 9. 채팅 응답 알림 받기

다른 창에서 작업 중일 때도 OS 알림을 받을 수 있습니다.

- `chat.notifyWindowOnResponseReceived`: 응답 수신 시 알림 표시 조건
- `chat.notifyWindowOnConfirmation`: 에이전트가 입력 또는 확인을 요청할 때 알림 표시 조건
- 설정 값:
  - `off`
  - `windowNotFocused` (기본)
  - `always`

> 장기 실행 작업 중에도 상태를 파악하려면 `always`로 설정

## 10. 채팅 세션 내 프롬프트 탐색

단축키로 세션 내 항목 간 이동 가능:

- `Ctrl+Alt+Up`: 이전 프롬프트로 이동
- `Ctrl+Alt+Down`: 다음 프롬프트로 이동
- `Ctrl+Alt+PageUp`: 이전 코드 블록으로 이동
- `Ctrl+Alt+PageDown`: 다음 코드 블록으로 이동

## 11. 채팅 세션 저장 및 내보내기

### JSON 파일로 내보내기

1. 내보낼 세션 열기
2. 명령 팔레트에서 `Chat: Export Chat...` 실행
3. 위치 선택 후 저장

### 재사용 가능한 프롬프트로 저장

1. 저장할 세션 열기
2. 채팅 입력에 `/savePrompt` 입력 후 Enter
3. `.prompt.md` 파일이 생성되어 워크스페이스에 저장
4. 필요 시 템플릿을 검토하고 편집

### 채팅 메시지를 Markdown으로 복사

- 개별 메시지 복사: 응답 텍스트, 생각 단계, 도구 호출 포함
- 전체 복사: 세션 전체를 Markdown으로 복사
- 최종 응답 복사: 마지막 도구 호출 이후 최종 Markdown 섹션만 복사
