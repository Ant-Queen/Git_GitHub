# VS Code 에이전트 커스터마이징 개념

원문: https://code.visualstudio.com/docs/agents/concepts/customization

---

## 1. 한 줄 요약

커스터마이징은 AI 에이전트의 행동 방식을 프로젝트와 팀의 요구에 맞게 조정하는 방법입니다.

---

## 2. 왜 필요한가?

기본 AI는 일반적인 지식을 갖고 있지만, 각 프로젝트의 규칙이나 워크플로는 다릅니다. 커스터마이징을 통해 다음이 가능합니다.

- 코드 스타일과 규칙을 자동 적용하기
- 반복 작업을 자동화하기
- 역할별 에이전트를 만들기
- 외부 데이터와 도구를 연결하기

---

## 3. 주요 커스터마이징 종류

- 커스텀 지시사항: 프로젝트 규칙을 지속적으로 알려줌
- 프롬프트 파일: 자주 쓰는 작업을 재사용 가능하게 저장
- 에이전트 스킬: 반복 업무 절차를 패키지로 제공
- 커스텀 에이전트: 역할별 에이전트 생성
- MCP: 외부 서비스와 연결
- 훅(Hooks): 특정 이벤트에서 자동 실행
- 에이전트 플러그인: 여러 설정을 묶어 배포

---

## 4. 활용 순서

1. 먼저 프로젝트 규칙을 지시사항으로 정리합니다.
2. 자주 쓰는 작업은 프롬프트나 스킬로 저장합니다.
3. 더 복잡한 역할 분담이 필요하면 커스텀 에이전트를 만듭니다.
4. 외부 정보가 필요하면 MCP를 추가합니다.

---

## 5. 핵심 정리

커스터마이징은 AI에게 “내 프로젝트의 언어를 알려주는 설정”입니다. 잘 쓰면 작업의 일관성과 효율을 크게 높일 수 있습니다.
