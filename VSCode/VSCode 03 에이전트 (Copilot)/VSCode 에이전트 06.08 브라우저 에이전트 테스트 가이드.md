# VSCode 에이전트 06.08 브라우저 에이전트 테스트 가이드

## 한줄 요약
브라우저 에이전트 도구를 사용하면 AI가 웹 앱을 직접 만들고, 웹 페이지를 열어 동작을 검증하며, 발견한 문제를 수정하는 흐름을 자동으로 수행할 수 있습니다.

## 핵심 개념
- 브라우저 도구를 사용하면 AI가 웹 페이지를 열고 상호작용할 수 있습니다.
- 주요 기능: 페이지 열기, 클릭, 입력, 스크린샷, 드래그, 다이얼로그 처리
- 에이전트는 웹 앱을 생성하고 테스트하는 과정까지 이어서 수행할 수 있습니다.
- 기본적으로 에이전트가 직접 연 페이지는 격리된 세션에서 동작합니다.

## 실무 예시
- “계산기 앱을 만들어줘”
- “이 페이지에서 버튼 동작을 검증해줘”
- “0으로 나누는 경우를 테스트하고 버그를 수정해줘”

## 핵심 정리
브라우저 에이전트는 웹 개발의 빌드-테스트-디버깅 루프를 자동화하는 데 특히 유용합니다.
