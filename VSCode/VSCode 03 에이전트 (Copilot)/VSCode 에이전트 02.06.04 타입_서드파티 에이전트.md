# 서드파티 에이전트 정리

원문: https://code.visualstudio.com/docs/agents/agent-types/third-party-agents

---

## 1. 한 줄 요약

서드파티 에이전트는 Anthropic, OpenAI 같은 외부 제공자의 에이전트를 VS Code 안에서 사용하는 방식입니다. VS Code의 통합 세션 관리와 편집 경험을 그대로 활용하면서, 다른 제공자의 강점을 쓸 수 있습니다.

---

## 2. 왜 쓰나?

- 각 제공자마다 서로 다른 강점과 특화 기능이 있습니다.
- VS Code 안에서 하나의 통합된 인터페이스로 관리할 수 있습니다.
- 디버깅, 테스트, 편집 같은 VS Code 기능과 연계할 수 있습니다.
- 기존 GitHub Copilot 구독으로도 사용할 수 있는 경우가 있습니다.

---

## 3. 지원되는 예

### Claude Agent

- Anthropic의 Claude 에이전트를 VS Code에서 사용할 수 있습니다.
- 로컬 또는 클라우드 세션으로 시작할 수 있습니다.
- 특정 작업에 맞는 슬래시 명령이 제공됩니다.

### OpenAI Codex

- OpenAI의 Codex 기반 에이전트를 사용할 수 있습니다.
- 로컬 또는 클라우드 세션으로 실행할 수 있습니다.

---

## 4. 사용 전 준비

- 클라우드 기반 서드파티 에이전트를 쓰려면 GitHub Copilot 계정 설정에서 해당 기능을 허용해야 할 수 있습니다.
- 일부 에이전트는 별도 확장 설치가 필요할 수 있습니다.

---

## 5. 시작하는 방법

1. Chat view에서 새 채팅을 생성합니다.
2. 세션 타입을 선택합니다.
   - 로컬 세션: Claude 또는 Codex 선택
   - 클라우드 세션: Cloud를 선택한 뒤 파트너 에이전트 선택
3. 프롬프트를 입력합니다.

---

## 6. 주의할 점

- 클라우드 서드파티 에이전트 기능은 현재 미리보기 상태일 수 있습니다.
- 일부 설정은 조직 정책에 의해 제한될 수 있습니다.
- 민감한 환경에서는 권한 설정을 신중히 확인해야 합니다.

---

## 7. 핵심 정리

서드파티 에이전트는 "VS Code 안에서 다른 회사의 에이전트도 같은 방식으로 쓰게 해주는 확장 기능"이라고 보면 됩니다.
