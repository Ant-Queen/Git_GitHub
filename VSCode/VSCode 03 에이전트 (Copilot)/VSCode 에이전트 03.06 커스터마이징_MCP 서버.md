# VS Code 에이전트 커스터마이징 - MCP Servers

원문: https://code.visualstudio.com/docs/agent-customization/mcp-servers

---

## 1. 한 줄 요약

MCP Server는 VS Code의 AI가 외부 도구, 데이터, 서비스와 연결돼 더 현실적인 작업을 수행하게 해 주는 기능입니다.

---

## 2. MCP란 무엇인가?

Model Context Protocol(MCP)은 AI가 외부 시스템과 상호작용할 수 있게 해 주는 표준입니다.

예를 들어 다음과 같은 작업에 쓰입니다.

- 데이터베이스 조회
- GitHub 이슈 관리
- 웹 브라우저 제어
- 외부 API 호출

---

## 3. 왜 쓰나?

기본적으로 AI는 코드와 로컬 파일만 다루기 쉽지만, 실제 작업은 외부 서비스와 연동해야 하는 경우가 많습니다.
MCP를 쓰면 다음이 가능합니다.

- 프로젝트 외부 데이터 활용
- 실서비스 도구와 연결
- 브라우저 기반 작업 자동화
- 도구 호출을 체계적으로 분리해서 관리

---

## 4. 기본 사용 흐름

1. MCP 서버를 설치합니다.
2. VS Code에서 서버를 등록합니다.
3. 서버가 제공하는 도구를 채팅에서 사용할 수 있게 됩니다.
4. 프롬프트에서 해당 도구를 호출해 작업합니다.

---

## 5. 설정 방식

MCP 서버는 보통 `mcp.json`에 등록합니다.

예시:

```json
{
  "servers": {
    "github": {
      "type": "http",
      "url": "https://api.githubcopilot.com/mcp"
    }
  }
}
```

이 파일은 워크스페이스 수준 또는 사용자 프로필 수준으로 둘 수 있습니다.

---

## 6. 보안 주의사항

MCP 서버는 로컬 코드를 실행할 수 있기 때문에 신뢰할 수 있는 서버만 사용해야 합니다.

특히 다음을 주의해야 합니다.

- 출처가 신뢰 가능한지 확인하기
- API 키나 비밀정보를 하드코딩하지 않기
- 필요 시 샌드박싱 사용하기

---

## 7. 추가 기능

MCP 서버는 도구 외에도 다음을 제공할 수 있습니다.

- Resources: 컨텍스트로 읽을 데이터 제공
- Prompts: 표준 템플릿 제공
- MCP Apps: 채팅 안에서 UI를 렌더링

---

## 8. 핵심 정리

MCP Server는 AI에게 “외부 세계의 도구와 데이터에 접근할 수 있는 통로”를 제공합니다. 이를 잘 활용하면 코드 작업이 훨씬 현실적인 환경에 맞게 확장됩니다.
