# VS Code 에이전트 커스터마이징 - Hooks

원문: https://code.visualstudio.com/docs/agent-customization/hooks

---

## 1. 한 줄 요약

Hooks는 에이전트의 생명주기 지점마다 자동으로 명령을 실행해, 포맷, 검증, 보안 정책, 로깅 등을 자동화하는 기능입니다.

---

## 2. 왜 쓰나?

지시문이나 프롬프트는 AI가 따르도록 유도하지만, Hooks는 실제로 실행되는 자동화 장치입니다.

다음 같은 작업에 유용합니다.

- 파일 수정 후 자동 포맷 실행
- 위험한 명령을 차단
- 테스트 자동 실행
- 작업 로그 기록
- 세션 시작/종료 시 컨텍스트 준비

---

## 3. 기본 개념

Hook은 다음 세 가지로 구성됩니다.

- 이벤트: 언제 실행할지
- 명령: 무엇을 실행할지
- 입력/출력: 이벤트 정보를 읽고 결과를 반환할지

예를 들어 `PostToolUse` 이벤트는 도구 사용 후 실행됩니다.

---

## 4. 대표적인 이벤트

- `SessionStart`: 세션 시작 시
- `UserPromptSubmit`: 사용자가 프롬프트를 보냈을 때
- `PreToolUse`: 도구 사용 전에
- `PostToolUse`: 도구 사용 후
- `Stop`: 세션 종료 시

---

## 5. 설정 방식

Hooks는 JSON 설정 파일로 정의합니다.
예시:

```json
{
  "hooks": {
    "PostToolUse": [
      {
        "type": "command",
        "command": "npx prettier --write ."
      }
    ]
  }
}
```

이 파일은 워크스페이스나 사용자 설정 디렉터리에 두면 됩니다.

---

## 6. 실무 팁

- 보안 정책을 강제하는 데 특히 강력합니다.
- 포맷/정적 검사 같은 반복 작업을 자동화하기 좋습니다.
- 내부 스크립트를 수정할 수 있는 권한이 생기지 않도록 주의해야 합니다.

---

## 7. 보안 주의사항

Hooks는 셸 명령을 실행하므로 잘못된 설정은 위험할 수 있습니다.

- 신뢰할 수 있는 스크립트만 사용하기
- 비밀정보를 코드에 하드코딩하지 않기
- 필요한 권한만 주기

---

## 8. 핵심 정리

Hooks는 “에이전트의 동작 지점마다 자동으로 로직을 실행하는 안전장치”입니다. 반복 자동화와 보안 정책 강화에 매우 유용합니다.
