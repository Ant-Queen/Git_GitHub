# VS Code 에이전트 계획 정리

원문: https://code.visualstudio.com/docs/agents/planning

---

## 1. 한 줄 요약

Plan 에이전트는 구현 전에 계획을 먼저 세우도록 도와주는 기능입니다. 복잡한 작업을 체계적으로 나누고, 요구사항 누락이나 잘못된 구현을 줄이는 데 유용합니다.

---

## 2. 왜 쓰나?

- 기능 추가, 리팩터링, 버그 수정처럼 여러 단계가 필요한 작업에 적합합니다.
- 구현 전에 구조를 먼저 확인해 불필요한 수정을 줄일 수 있습니다.
- 팀에서 공통된 작업 방식과 검증 기준을 정하기 좋습니다.

---

## 3. 기본 사용 방법

1. Chat view를 열고 에이전트 선택 메뉴에서 `Plan`을 선택합니다.
2. 또는 채팅 입력창에 `/plan`을 입력한 뒤 작업 내용을 적습니다.
3. 에이전트가 질문을 하면 답변합니다.
4. Plan 에이전트가 계획 요약, 구현 단계, 검증 단계를 제안합니다.
5. 계획을 검토한 뒤 필요하면 수정하고, 이어서 구현합니다.

예시:

- `/plan Add unit tests for all API endpoints`
- `Implement a user authentication system with OAuth2 and JWT`

---

## 4. 계획이 저장되는 방식

- Plan 에이전트는 세션 메모리 파일인 `/memories/session/plan.md`에 계획을 자동 저장합니다.
- `Chat: Show Memory Files` 명령으로 해당 파일을 열어 확인할 수 있습니다.
- 세션이 끝나면 이 메모리는 사라지므로, 이후 세션에서는 다시 확인할 수 없습니다.

---

## 5. 사용자화하기

### 커스텀 계획 에이전트

- 팀의 아키텍처 규칙, 문서 형식, 검증 기준을 반영한 계획 에이전트를 만들 수 있습니다.

### 모델 선택

- `chat.planAgent.defaultModel` 설정으로 Plan 에이전트의 기본 모델을 지정할 수 있습니다.
- 구현 단계에서 사용할 모델은 별도로 설정할 수 있습니다.

### 추가 도구 사용

- MCP 서버 등 추가 도구를 계획 단계에 연결해 더 풍부한 조사와 계획을 수행할 수 있습니다.

---

## 6. 실무 팁

- 한 번에 너무 큰 작업을 주지 말고, 먼저 큰 목표를 나눠서 계획합니다.
- 구현 전에 검증 기준(테스트, 예상 결과)을 함께 적어두면 더 안정적입니다.
- 계획이 충분히 검토된 뒤 구현 단계로 넘어가면 재작업을 줄일 수 있습니다.

---

## 7. 핵심 정리

Plan 에이전트는 “코딩 전에 먼저 설계하는 에이전트”라고 생각하면 됩니다. 복잡한 작업을 구조적으로 정리해 주고, 구현 단계가 더 안정적으로 진행되도록 돕습니다.
