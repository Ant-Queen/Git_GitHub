# VS Code 신뢰와 안전 개념

원문: https://code.visualstudio.com/docs/agents/concepts/trust-and-safety

---

## 1. 한 줄 요약

신뢰와 안전은 AI가 파일 수정, 명령 실행, 외부 서비스 호출을 할 때 사용자가 여전히 통제권을 가질 수 있도록 하는 메커니즘입니다.

---

## 2. 왜 중요한가?

AI 에이전트는 강력한 기능을 수행할 수 있지만, 잘못된 실행은 코드나 시스템에 영향을 줄 수 있습니다. 그래서 승인, 검토, 격리 같은 장치가 필요합니다.

---

## 3. 주요 보안/안전 장치

### 변경사항 검토
- 파일 수정은 diff로 보여주고, 사용자가 승인하거나 되돌릴 수 있습니다.

### 승인 기반 실행
- 터미널 명령이나 도구 실행 전에 확인을 요구할 수 있습니다.

### 권한 수준
- 에이전트의 자율성을 낮추거나 높일 수 있습니다.

### 샌드박싱
- 터미널 명령이 허용된 범위 밖으로 확장되지 않도록 격리합니다.

### 네트워크 제한
- 외부 도메인 접근을 제한해 의도치 않은 외부 작업을 막습니다.

---

## 4. AI의 한계도 고려해야 함

- AI가 틀린 답을 내놓을 수 있습니다.
- 프롬프트 인젝션 같은 공격에 노출될 수 있습니다.
- 따라서 결과를 무조건 신뢰하지 말고 검토해야 합니다.

---

## 5. 핵심 정리

에이전트는 강력하지만, 그만큼 안전장치가 필요합니다. 사용자는 승인, 검토, 샌드박싱, 권한 제한을 통해 AI의 행동을 통제할 수 있습니다.
