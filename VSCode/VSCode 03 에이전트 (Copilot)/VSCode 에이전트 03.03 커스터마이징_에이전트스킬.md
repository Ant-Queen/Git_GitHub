# VS Code 에이전트 커스터마이징 - Agent Skills

원문: https://code.visualstudio.com/docs/agent-customization/agent-skills

---

## 1. 한 줄 요약

Agent Skills는 테스트, 디버깅, 배포 같은 반복 작업을 재사용 가능한 형태로 저장해 두는 기능입니다.

---

## 2. 무엇이 특별한가?

Custom Instructions가 규칙을 알려주는 데 초점이라면, Agent Skills는 “어떻게 작업할지”까지 포함한 실행 가능한 지식 묶음입니다.

Skills는 보통 다음을 포함합니다.

- 지시문
- 스크립트
- 예시 파일
- 참고 자료

---

## 3. 왜 쓰나?

다음 같은 상황에 유용합니다.

- 테스트 실행 루틴을 반복하고 싶을 때
- 배포 절차를 자동화하고 싶을 때
- 디버깅 흐름을 표준화하고 싶을 때
- 팀에서 공통 워크플로를 공유하고 싶을 때

---

## 4. 기본 구조

Skill은 보통 다음 형태로 구성됩니다.

- `SKILL.md`: 실행 지침이 들어가는 핵심 파일
- 스크립트 파일: 실제로 실행되는 도구들
- 예시 디렉터리: 참고용 템플릿이나 샘플

예시 파일 이름은 `SKILL.md`로 정해져 있습니다.

---

## 5. 사용 방식

- `/skills` 명령으로 관리할 수 있습니다.
- 필요할 때 자동으로 로드되거나, `/skill-name`처럼 직접 실행할 수 있습니다.
- 관련 작업이 있을 때만 컨텍스트에 적재되어 효율적입니다.

---

## 6. 실무 팁

- Skill은 너무 넓게 만들기보다 “한 가지 작업에 특화된 것”으로 만드는 것이 좋습니다.
- 실행 절차는 단계별로 쓰고, 기대 결과도 같이 적으면 좋습니다.
- 공유 Skill은 보안상 검토한 뒤 사용해야 합니다.

---

## 7. 핵심 정리

Agent Skills는 “반복 업무를 패키지처럼 재사용 가능한 능력으로 저장하는 기능”입니다. 프로젝트나 팀 단위로 잘 활용하면 효율이 크게 올라갑니다.

---
