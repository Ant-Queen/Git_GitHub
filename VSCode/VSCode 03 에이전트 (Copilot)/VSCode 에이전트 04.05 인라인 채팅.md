# VS Code 인라인 채팅

원문: https://code.visualstudio.com/docs/chat/inline-chat

---

## 1. 한 줄 요약

인라인 채팅은 현재 열려 있는 파일 안에서 바로 질문하고 수정하는 빠른 채팅 방식입니다.

---

## 2. 언제 쓰면 좋나?

다음 같은 상황에 특히 유용합니다.

- 현재 코드의 일부를 바로 수정하고 싶을 때
- 특정 함수의 동작을 설명하고 싶을 때
- 터미널에서 명령을 바로 생성하고 싶을 때
- 별도의 채팅 화면을 열지 않고 빠르게 작업하고 싶을 때

---

## 3. 기본 사용 방법

- 에디터에서 Ctrl+I를 누르면 인라인 채팅을 열 수 있습니다.
- 특정 코드 블록을 선택하면 그 범위에 맞게 요청할 수 있습니다.
- 제안된 변경사항은 바로 diff로 확인하고 수락하거나 취소할 수 있습니다.

---

## 4. 장점

- 작업 흐름을 끊지 않고 바로 이어서 할 수 있습니다.
- 작은 수정이나 빠른 설명에 적합합니다.
- 코드 컨텍스트를 바로 반영해 더 자연스럽게 작업할 수 있습니다.

---

## 5. 한계

- 여러 파일을 한 번에 수정하거나 복잡한 작업은 채팅 보기보다 불편할 수 있습니다.
- 긴 대화나 여러 단계의 작업은 세션 기반 채팅이 더 적합합니다.

---

## 6. 핵심 정리

인라인 채팅은 “지금 보고 있는 코드 위에서 바로 AI와 상호작용하는 기능”입니다. 빠르고 가벼운 수정에 매우 적합합니다.
