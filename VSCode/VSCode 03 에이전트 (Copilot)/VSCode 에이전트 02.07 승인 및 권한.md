# 승인 및 권한 관리 정리

원문: https://code.visualstudio.com/docs/agents/approvals

---

## 1. 한 줄 요약

VS Code의 에이전트는 파일 수정, 터미널 명령 실행, 외부 URL 접근 같은 작업을 할 수 있기 때문에, 사용자가 승인 수준과 권한을 직접 제어할 수 있도록 설계되어 있습니다.

---

## 2. 왜 승인 관리가 필요한가?

에이전트는 강력한 작업을 수행할 수 있습니다.

- 파일을 수정할 수 있고
- 터미널 명령을 실행할 수 있고
- 외부 URL을 불러올 수 있습니다.

그래서 실수로 위험한 행동을 하거나, 악의적인 입력에 따라 잘못된 행동을 하지 않도록 승인 제어가 필요합니다.

---

## 3. 권한 수준(Permission Levels)

권한 수준은 세션에서 에이전트가 얼마나 자율적으로 행동할지 결정합니다.

### 1) Default Approvals

- 기본값입니다.
- 승인 설정을 따릅니다.
- 도구나 명령이 실행되기 전에 확인 창이 뜰 수 있습니다.

### 2) Bypass Approvals

- 모든 도구 실행을 자동 승인합니다.
- 확인창이 거의 안 뜹니다.
- 빠르지만 위험도 높습니다.

### 3) Autopilot

- 자동 승인 + 자동 재시도 + 모호한 질문에 자동 응답까지 수행합니다.
- 매우 자율적이지만, 실수나 위험도 커질 수 있습니다.

> 참고: Bypass와 Autopilot은 잠재적으로 파괴적인 작업도 자동으로 허용할 수 있으므로 신중히 사용해야 합니다.

---

## 4. 도구 승인(Tool Approval)

도구가 실행되기 전에는 확인 창이 뜰 수 있습니다.

예를 들어:

- 파일 수정 도구
- 터미널 실행 도구
- 외부 서비스 접근 도구

사용자는 다음 중 하나로 승인할 수 있습니다.

- 한 번만 승인
- 현재 세션 동안 승인
- 현재 워크스페이스에서 승인
- 앞으로 계속 승인

### 보안 팁

- 민감한 파일(예: `.env`, 설정 파일)은 특히 주의해야 합니다.
- 수시로 승인했던 도구는 실수로 자동 승인되지 않도록 관리할 수 있습니다.

---

## 5. URL 승인(URL Approval)

에이전트가 URL을 읽어오려고 할 때, 두 단계의 승인 절차가 있습니다.

### 1) 요청 승인

- 어떤 도메인에 요청할지 승인합니다.
- 신뢰할 수 없는 사이트로 민감한 정보가 가는 것을 막습니다.

### 2) 응답 승인

- 가져온 내용을 채팅에 반영하기 전에 확인합니다.
- 외부 페이지의 내용이 에이전트를 조작하는 프롬프트 인젝션에 사용될 수 있기 때문입니다.

---

## 6. 터미널 명령 자동 승인

터미널 명령은 매우 강력해서, 명령 단위로 승인 여부를 정하는 방식이 사용됩니다.

### 설정 예시

- 특정 명령은 자동 승인 가능
- 특정 명령은 항상 승인 필요
- 정규식 패턴으로 세밀하게 제어 가능

예:

- `mkdir`는 허용 가능
- `rm`이나 `del`은 기본적으로 차단

### 주의사항

- 자동 승인 기능은 편리하지만, 프롬프트 인젝션이나 안전하지 않은 명령에 취약할 수 있습니다.
- 고위험 환경에서는 샌드박스 사용을 권장합니다.

---

## 7. 샌드박스(Sandbox)

샌드박스는 에이전트가 실행하는 명령의 파일 시스템과 네트워크 접근을 제한합니다.

### 주요 기능

- 파일 시스템 접근 제한
- 네트워크 접근 제한
- 샌드박스 안에서 실행된 명령은 더 안전하게 처리

### 예시 제어 항목

- 읽기 허용 경로 지정
- 쓰기 허용 경로 지정
- 차단할 경로 지정
- 허용/차단할 네트워크 도메인 지정

---

## 8. 실전에서 추천하는 사용법

- 처음에는 `Default Approvals`로 시작하기
- 중요한 작업에서는 수동 승인 중심으로 사용하기
- 터미널 명령은 꼭 필요한 것만 자동 승인하기
- 민감한 파일은 항상 확인하기
- 고위험 작업에서는 샌드박스 사용하기

---

## 9. 핵심 정리

VS Code 에이전트의 승인 및 권한 관리 기능은 “에이전트에게 충분히 자동화된 힘을 주되, 사용자가 안전하게 통제할 수 있게 하는 장치”입니다.
