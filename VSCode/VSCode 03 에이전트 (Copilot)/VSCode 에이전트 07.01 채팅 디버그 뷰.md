# VSCode 에이전트 07.01 채팅 디버그 뷰

## 한줄 요약
VS Code의 채팅 디버그 도구는 AI 요청이 어떻게 처리되는지 원시 데이터 수준에서 확인할 수 있게 해 주는 기능입니다.

## 핵심 개념
- Agent Debug Log panel: 세션 중 발생한 이벤트를 시간순으로 보여줍니다.
- Chat Debug view: 각 요청의 시스템 프롬프트, 사용자 프롬프트, 컨텍스트, 도구 호출 결과를 확인할 수 있습니다.
- Logs, Summary, Agent Flow Chart, Cache Explorer 같은 하위 뷰를 전환해 분석할 수 있습니다.

## 실제 사용 상황
- AI가 워크스페이스 파일을 무시하는 경우
- MCP 도구가 호출되지 않는 경우
- 응답이 잘린 경우
- 커스텀 인스트럭션이나 프롬프트 파일이 적용되지 않는 경우

## 실무 팁
- 디버그 패널에서 이벤트와 도구 호출 흐름을 확인한다.
- 컨텍스트 섹션에서 필요한 파일이 실제로 포함되었는지 점검한다.
- 문제가 반복되면 세션을 새로 시작해 컨텍스트를 초기화한다.

## 핵심 정리
AI가 예상과 다르게 동작할 때는 “결과만 보는 것”보다 요청/컨텍스트/도구 호출 흐름을 직접 확인하는 것이 가장 빠릅니다.
