# 클라우드 에이전트 정리

원문: https://code.visualstudio.com/docs/agents/agent-types/cloud-agents

---

## 1. 한 줄 요약

클라우드 에이전트는 로컬이 아닌 원격 인프라에서 실행되는 에이전트입니다. GitHub 저장소와 잘 연결되어 있어, 팀 협업과 PR 기반 작업에 강합니다.

---

## 2. 어떤 특징이 있나?

- 로컬 머신이 아닌 원격 환경에서 실행됩니다.
- GitHub 저장소와 연동되어 PR을 만들거나 리뷰 작업을 이어갈 수 있습니다.
- 로컬에서 바로 확인하기 어려운 대규모 작업에 적합합니다.
- 사용자 상호작용 없이도 독립적으로 작업할 수 있습니다.

---

## 3. 이런 상황에 적합하다

- 큰 기능 구현
- 코드 리팩터링
- 리뷰 의견 반영
- PR 생성 및 협업 흐름 관리

---

## 4. 시작하는 방법

1. Chat view에서 새 채팅을 생성합니다.
2. 세션 타입을 Cloud로 설정합니다.
3. 사용할 클라우드 에이전트(provider)를 선택합니다.
4. 작업 요청을 입력합니다.

예시 프롬프트:

- "인증 모듈을 리팩터링해줘"
- "보안과 성능을 개선하는 방향으로 구현해줘"

---

## 5. 로컬/백그라운드 세션에서 넘기는 방법

복잡한 작업은 먼저 로컬 에이전트나 Copilot CLI 세션으로 계획을 세운 뒤, 클라우드 에이전트로 넘길 수 있습니다.

- 대화 맥락을 그대로 전달할 수 있습니다.
- 복잡한 구현을 자동으로 이어서 진행할 수 있습니다.

---

## 6. 관리 방법

VS Code의 Chat view에서 클라우드 세션을 확인하고 관리할 수 있습니다.

- 세션 목록에서 클라우드 세션만 필터링할 수 있습니다.
- 세션 상세를 열어 진행 상황을 확인할 수 있습니다.

---

## 7. 핵심 정리

클라우드 에이전트는 "팀 협업과 PR 중심 작업에 맞춘 원격형 에이전트"라고 보면 됩니다.
