# VSCode 에이전트 06.02 컨텍스트 엔지니어링 가이드

## 한줄 요약
컨텍스트 엔지니어링은 에이전트가 작업할 때 필요한 정보를 미리 잘 정리해 두는 방식이며, 프로젝트 문서와 지침을 체계적으로 제공하는 것이 핵심입니다.

## 핵심 개념
- 프로젝트 전반의 맥락을 정리해 두면 AI의 판단 품질이 높아진다.
- 대표적인 컨텍스트 자료: PRODUCT.md, ARCHITECTURE.md, CONTRIBUTING.md
- .github/copilot-instructions.md를 두면 모든 채팅에 공통 컨텍스트를 자동 포함할 수 있다.
- 플래닝 에이전트나 템플릿을 사용하면 구현 계획을 더 체계적으로 만들 수 있다.

## 실무 흐름
1. 프로젝트 문서 정리
2. 공통 지침 파일 작성
3. 구현 계획 템플릿 구성
4. 구현 에이전트로 코드 생성

## 실무 팁
- 처음부터 너무 많은 지침을 넣지 말고, 핵심적인 규칙부터 시작한다.
- 컨텍스트는 최신 상태로 유지해야 한다.
- 계획 → 구현 → 검토처럼 단계별 흐름을 나누면 품질이 높아진다.

## 핵심 정리
에이전트는 “좋은 맥락”을 받으면 더 정확하고 일관된 결과를 만든다.
