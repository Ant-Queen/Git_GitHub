# VS Code 에이전트 커스터마이징 개요

원문: https://code.visualstudio.com/docs/agent-customization/overview

---

## 1. 한 줄 요약

에이전트 커스터마이징은 VS Code의 AI가 내 프로젝트와 팀 방식에 맞게 동작하도록 설정하는 기능입니다.

---

## 2. 왜 필요한가?

AI가 코드를 잘 작성하더라도, 팀 규칙, 아키텍처, 반복 작업 방식은 프로젝트마다 다릅니다.
커스터마이징을 사용하면 다음이 가능합니다.

- 프로젝트 규칙을 한 번 정의해 두고 반복적으로 적용하기
- 특정 역할에 맞는 에이전트 설정 만들기
- 외부 도구나 데이터 소스 연결하기
- 자주 쓰는 작업을 자동화하기

---

## 3. 주요 커스터마이징 종류

### 1) Custom Instructions
- 코드 스타일, 아키텍처 규칙, 보안 기준 같은 기본 규칙을 넣는 방식입니다.
- 모든 채팅 요청에 자동으로 반영됩니다.

### 2) Agent Skills
- 테스트, 배포, 디버깅 같은 반복 가능한 업무 절차를 패키지처럼 저장하는 방식입니다.
- 필요할 때 자동으로 로드됩니다.

### 3) Custom Agents
- 리뷰어, 플래너, 구현 담당자 같은 역할별 에이전트를 만들 수 있습니다.
- 각 에이전트마다 도구와 지시문을 다르게 설정할 수 있습니다.

### 4) MCP Servers
- DB, API, 외부 툴 등과 AI를 연결해 실제 데이터를 바탕으로 작업하게 합니다.

### 5) Hooks
- 에이전트가 파일을 수정하거나 도구를 실행할 때 자동으로 명령을 실행합니다.
- 포맷, 검사, 로깅, 보안 정책에 유용합니다.

### 6) Agent Plugins
- 여러 커스터마이징을 묶어 하나의 플러그인 형태로 배포할 수 있습니다.

### 7) Prompt Files
- 자주 쓰는 작업을 `/명령어` 형태로 실행할 수 있게 만드는 재사용형 프롬프트입니다.

---

## 4. 시작하는 추천 순서

1. 먼저 프로젝트 공통 규칙을 넣기 위해 Custom Instructions부터 설정합니다.
2. 반복 작업이 있으면 Agent Skills를 추가합니다.
3. 역할별로 분업이 필요하면 Custom Agents를 만듭니다.
4. 외부 도구를 쓰고 싶으면 MCP Server를 연결합니다.
5. 자동화가 필요하면 Hooks를 추가합니다.

---

## 5. 실무 팁

- 처음부터 모든 기능을 넣기보다, 자주 반복되는 필요부터 하나씩 추가하는 것이 좋습니다.
- 설명은 짧고 명확하게 쓰는 것이 효과적입니다.
- 에이전트 커스터마이징 파일은 프로젝트에 함께 저장하면 팀 공유도 쉬워집니다.

---

## 6. 모노레포란 무엇인가?

모노레포는 하나의 저장소 안에 여러 프로젝트나 패키지를 함께 관리하는 방식입니다.
예를 들어 프론트엔드, 백엔드, 공용 UI 라이브러리 등을 같은 Git 저장소 안에서 관리하는 것이죠.

이 방식은 여러 프로젝트를 한 번에 다루기 쉽고, 공통 코드를 재사용하기 좋다는 장점이 있습니다.

## 7. 모노레포에서 커스터마이징 사용하기

모노레포에서는 보통 저장소 루트가 아닌, 특정 패키지나 서브폴더만 열고 작업하는 경우가 많습니다.
이때 기본 설정으로는 현재 열린 폴더 아래의 커스터마이징 파일만 인식할 수 있지만, `chat.useCustomizationsInParentRepositories` 설정을 켜면 상위 저장소의 커스터마이징 파일도 같이 읽어올 수 있습니다.

- 예를 들어 `packages/frontend`만 열어도, 저장소 루트의 `copilot-instructions.md`, `instructions`, `prompts`, `agents`, `skills`, `hooks` 파일을 적용받을 수 있습니다.
- 이 기능은 모노레포에서 팀 공통 규칙이나 공용 프롬프트를 재사용할 때 매우 유용합니다.
- 단, 상위 폴더가 Git 저장소이고, 해당 폴더가 신뢰된 워크스페이스로 인식되어야 합니다.

즉, 모노레포에서도 “프로젝트 루트 기준으로 공통 규칙을 한 번 정의하고, 하위 패키지에서 그대로 공유”하는 방식으로 사용할 수 있습니다.

---

## 8. 핵심 정리

VS Code의 에이전트 커스터마이징은 “AI에게 내 프로젝트의 언어를 알려주는 설정”입니다. 적절히 사용하면 반복 작업을 줄이고, 더 일관된 결과를 얻을 수 있습니다.
