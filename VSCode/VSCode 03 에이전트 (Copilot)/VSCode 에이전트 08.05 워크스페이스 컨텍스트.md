# VSCode 에이전트 08.05 워크스페이스 컨텍스트

## 한줄 요약
워크스페이스 컨텍스트는 Copilot 에이전트가 코드베이스를 어떻게 이해하고 검색하는지, 그리고 어떤 정보가 컨텍스트로 사용되는지 설명하는 문서입니다.

## 핵심 개념
- 에이전트는 워크스페이스의 파일, 디렉터리 구조, 심볼, 선택한 코드, 대화 기록 등을 바탕으로 작업합니다.
- 검색 도구는 텍스트 검색, 파일 검색, 심볼 사용 위치 탐색, 심볼릭 의미 검색을 포함합니다.
- 시맨틱 인덱스가 있으면 “키워드”보다 “의미”에 가까운 검색이 가능합니다.
- .gitignore, files.exclude, search.exclude를 잘 설정하면 검색 노이즈를 줄일 수 있습니다.
- 대규모 프로젝트에서는 검색 범위를 좁히는 설정이 성능과 비용 관리에 매우 중요합니다.

## 실무 팁
- 프롬프트는 구체적으로 쓰는 것이 좋습니다. “이 함수가 뭐야?”보다 “이 함수의 예외 처리 흐름을 설명해줘”처럼 쓰면 더 좋습니다.
- 검색 결과가 너무 많으면 제외 설정을 조정해 컨텍스트를 정리합니다.
- 비공개 저장소를 쓸 때는 권한 승인 흐름을 확인합니다.

## 핵심 정리
에이전트의 품질은 “좋은 질문”과 “정리된 컨텍스트”에 크게 좌우됩니다.
