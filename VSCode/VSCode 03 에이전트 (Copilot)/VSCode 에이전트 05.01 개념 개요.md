# VS Code 에이전트 개념 개요

원문: https://code.visualstudio.com/docs/agents/concepts/overview

---

## 1. 한 줄 요약

VS Code의 AI 기능은 언어 모델, 컨텍스트, 도구, 에이전트, 커스터마이징, 신뢰와 안전이라는 기본 개념들이 함께 작동하는 구조입니다.

---

## 2. 어디에 쓰이나?

VS Code에서는 AI가 다음처럼 사용됩니다.

- 채팅으로 질문하기
- 코드 수정 요청하기
- 테스트 및 디버깅 도와주기
- 여러 파일에 걸친 작업 자동화하기

---

## 3. 핵심 개념 연결

- 언어 모델: 답변을 생성하는 두뇌 역할
- 컨텍스트: 모델이 참고할 수 있는 정보
- 도구: 파일 읽기, 수정, 터미널 실행, 외부 서비스 연결
- 에이전트: 이 모든 요소를 이어서 목표를 수행하는 실행 주체
- 커스터마이징: 프로젝트 규칙과 작업 방식을 AI에 맞게 조정
- 신뢰와 안전: 잘못된 행동을 막고 사용자가 통제할 수 있게 하는 장치

---

## 4. 이해하기 쉬운 관점

VS Code의 AI는 “단순한 답변기”가 아니라, 상황을 이해하고 도구를 사용해 실제 작업을 수행하는 자동화 시스템입니다.

---

## 5. 핵심 정리

AI 기능을 제대로 쓰려면, 단순히 “질문하는 것”보다 “어떤 모델, 어떤 정보, 어떤 도구를 쓰는지”를 이해하는 것이 중요합니다.
