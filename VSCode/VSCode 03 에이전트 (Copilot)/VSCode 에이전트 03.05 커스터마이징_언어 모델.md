# VS Code 에이전트 커스터마이징 - Language Models

원문: https://code.visualstudio.com/docs/agent-customization/language-models

---

## 1. 한 줄 요약

언어 모델을 바꾸면 같은 작업도 더 빠르게, 더 정교하게, 더 적합한 방식으로 처리할 수 있습니다.

---

## 2. 모델을 바꾸는 이유

모델마다 강점이 다릅니다.

- 빠른 응답이 필요한 작업: 가벼운 모델
- 복잡한 설계나 리팩터링: 추론 능력이 좋은 모델
- 코드 생성: 코드에 강한 모델

즉, 작업에 따라 모델을 다르게 쓰는 것이 좋습니다.

---

## 3. VS Code에서 하는 기본 작업

- 채팅 모델 변경: 채팅 입력창의 모델 선택기에서 변경 가능
- Thinking Effort 조절: 복잡한 작업은 더 많은 사고량을 사용하도록 설정 가능
- Auto Model Selection: 작업의 복잡도에 따라 자동으로 모델을 선택

---

## 4. 모델 관리 기능

VS Code에서는 다음을 할 수 있습니다.

- 사용 가능한 모델 보기
- 모델 표시/숨김 관리
- 자주 쓰는 모델 고정하기
- BYOK(Bring Your Own Key)로 외부 모델 연결하기

---

## 5. BYOK란?

BYOK는 자신의 API 키로 외부 모델을 VS Code에 연결하는 방식입니다.

이 기능을 쓰면 다음이 가능합니다.

- OpenAI, Azure, Anthropic 등 다양한 공급자 모델 사용
- 로컬 모델 사용
- 기존에 없는 모델을 추가해서 테스트하기

---

## 6. 실무 팁

- 간단한 수정은 빠른 모델을 쓰고, 구조 설계나 디버깅은 강력한 모델을 쓰는 것이 효율적입니다.
- 복잡한 작업은 thinking effort를 조절하면 더 나은 결과를 얻을 수 있습니다.
- 로컬 모델을 사용할 경우, 기능 범위와 인터넷 의존성에 차이가 있음을 확인해야 합니다.

---

## 7. 핵심 정리

언어 모델 선택은 에이전트 성능에 큰 영향을 줍니다. 작업의 성격에 맞게 모델을 바꾸고, 필요하면 BYOK로 확장하는 것이 좋습니다.

---
