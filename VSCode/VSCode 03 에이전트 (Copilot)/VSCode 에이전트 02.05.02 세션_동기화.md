# 세션 동기화 정리

원문: https://code.visualstudio.com/docs/agents/sessions/session-sync

---

## 1. 한 줄 요약

세션 동기화는 Copilot 세션 기록을 GitHub 계정과 연결해, 여러 기기와 환경에서 세션을 다시 조회할 수 있게 해주는 기능입니다.

---

## 2. 기본 개념

기본적으로 VS Code는 채팅 세션을 GitHub 계정에 동기화합니다.

- 동기화된 세션은 기본적으로 비공개입니다.
- 다른 사람에게 보이려면 직접 공유해야 합니다.
- 세션 데이터는 개인 계정에 연결되어 관리됩니다.

---

## 3. 동기화 기능의 장점

- 다른 기기에서 세션을 다시 확인할 수 있습니다.
- 세션 히스토리 기반으로 인사이트 기능을 활용할 수 있습니다.
- Copilot CLI, coding agent, code review 등 다양한 세션 기록을 함께 관리할 수 있습니다.

---

## 4. 동기화 끄기

세션 동기화를 비활성화하려면 설정을 바꾸면 됩니다.

- `chat.sessionSync.enabled`를 `false`로 설정하면 로컬만 사용하게 됩니다.
- 특정 저장소는 동기화 대상에서 제외할 수도 있습니다.

예시 설정:

```json
"chat.sessionSync.excludeRepositories": [
  "my-org/private-repo",
  "my-org/secret-*"
]
```

---

## 5. 기업 정책과 관리

기업/조직 환경에서는 관리자 정책으로 세션 동기화를 강제하거나 제한할 수 있습니다.

- 조직 정책에 따라 동기화가 비활성화될 수 있습니다.
- 관리자가 정책을 끄면 사용자가 직접 켤 수 없습니다.

---

## 6. 세션 공유하기

동기화된 세션은 기본적으로 공유되지 않지만, GitHub에서 직접 공유할 수 있습니다.

- 저장소 협업자에게 보기 전용으로 공유 가능
- 공유된 세션은 프롬프트, 응답, 파일 변경 내용을 볼 수 있음
- 단, 세션을 조작하거나 이어서 진행할 수는 없음

---

## 7. 상태 확인과 삭제

세션 동기화 상태는 Copilot 상태 표시줄에서 확인할 수 있습니다.

상태 예시:

- Not enabled: 동기화 꺼짐
- Enabled: 동기화 중
- Sync error: 동기화 실패

동기화된 데이터를 삭제하려면 명령 팔레트를 통해 삭제 명령을 실행할 수 있습니다.

---

## 8. 보안과 개인정보

- 민감한 정보는 클라우드에 올리기 전에 자동으로 제거됩니다.
- 동기화된 세션은 기본적으로 본인만 접근 가능하다.
- 원하면 언제든지 동기화를 중단할 수 있습니다.

---

## 9. 핵심 정리

세션 동기화는 "내 작업 기록을 안전하게 클라우드에 보관하고, 필요할 때 다시 꺼내 쓰는 기능"입니다.
