# VS Code 도구 개념

원문: https://code.visualstudio.com/docs/agents/concepts/tools

---

## 1. 한 줄 요약

도구는 AI가 단순히 답하는 것이 아니라 실제 환경에서 행동할 수 있게 해 주는 기능입니다.

---

## 2. 도구가 왜 필요한가?

언어 모델은 텍스트를 생성할 수는 있어도, 직접 파일을 읽고 수정하거나 터미널을 실행하는 능력은 없습니다. 그래서 도구가 필요합니다.

---

## 3. 도구의 종류

### 내장 도구
- 파일 읽기/쓰기
- 검색
- 터미널 실행
- 문제 확인

### MCP 도구
- 외부 API, 데이터베이스, 서비스와 연결

### 확장 도구
- 확장 프로그램이 제공하는 추가 기능

---

## 4. 도구는 어떻게 쓰이나?

에이전트는 작업을 수행할 때 필요한 도구를 자동으로 선택합니다. 사용자가 직접 특정 도구를 지정할 수도 있습니다.

---

## 5. 도구 사용의 장점과 주의점

### 장점
- 실제 코드베이스를 분석할 수 있음
- 테스트나 빌드 같은 작업을 자동화할 수 있음
- 외부 시스템과 연결 가능

### 주의점
- 잘못된 도구 사용은 파일 변경이나 외부 서비스 호출을 일으킬 수 있음
- 보안과 승인 절차가 필요함

---

## 6. 핵심 정리

도구는 AI에게 “환경과 상호작용할 수 있는 손”을 주는 기능입니다. 제대로 쓰면 강력하지만, 관리와 승인도 중요합니다.
