# VS Code 채팅 도구

원문: https://code.visualstudio.com/docs/chat/chat-tools

---

## 1. 한 줄 요약

채팅 도구는 AI가 코드 검색, 터미널 실행, 웹 조회, 외부 API 호출 같은 작업을 실제로 수행하게 해 주는 기능입니다.

---

## 2. 도구가 왜 필요한가?

AI가 단순히 텍스트를 생성하는 것만으로는 실제 작업을 완성하기 어렵습니다. 예를 들어 다음과 같은 작업은 도구가 필요합니다.

- 코드베이스에서 정보 찾기
- 터미널에서 테스트 실행하기
- 웹에서 최신 정보 조회하기
- 외부 서비스와 연결하기

---

## 3. 도구의 종류

### 내장 도구
- 코드 검색, 문제 보기, 터미널 실행 등 기본 기능

### MCP 도구
- MCP 서버를 통해 외부 도구와 연결

### 확장 프로그램 도구
- 확장 기능이 제공하는 추가 도구

---

## 4. 사용 방법

- 채팅에서 AI가 필요에 따라 자동으로 도구를 선택합니다.
- 필요하면 #도구이름 형태로 특정 도구를 명시적으로 요청할 수도 있습니다.
- 도구를 선택해 사용 가능 여부를 미리 설정할 수도 있습니다.

---

## 5. 터미널 도구의 특징

- 긴 실행 작업은 백그라운드로 이어서 처리할 수 있습니다.
- 실행 결과는 채팅에서 바로 확인할 수 있습니다.
- 보안을 위해 승인 절차가 필요할 수 있습니다.

---

## 6. 실무 팁

- 필요한 도구만 켜 두는 것이 좋습니다.
- 민감한 작업은 승인 과정을 거치게 하는 것이 안전합니다.
- 도구 사용 결과를 체크해서 AI의 판단이 잘못되지 않았는지도 확인해야 합니다.

---

## 7. 핵심 정리

도구는 AI에게 “실제 행동”을 하게 해 주는 기능입니다. 코드 작업을 자동화하고, 더 현실적인 결과를 얻고 싶다면 도구를 잘 활용하는 것이 중요합니다.
