# VS Code 컨텍스트 개념

원문: https://code.visualstudio.com/docs/agents/concepts/context

---

## 1. 한 줄 요약

컨텍스트는 AI가 현재 작업을 이해하기 위해 참고하는 정보의 전체 집합입니다.

---

## 2. 왜 중요한가?

모델은 자신이 받은 정보만 보고 판단합니다. 따라서 질문만 던지는 것보다, 관련 파일이나 히스토리, 규칙을 함께 주는 것이 훨씬 좋습니다.

---

## 3. VS Code가 모으는 컨텍스트

VS Code는 다음 정보를 조합해 모델에 전달합니다.

- 시스템 지시사항
- 사용자 메시지
- 대화 히스토리
- 현재 열려 있는 파일
- 선택한 코드
- 파일/폴더 참조
- 도구 실행 결과
- 커스텀 지시사항

---

## 4. 명시적 컨텍스트와 암시적 컨텍스트

### 암시적 컨텍스트
- 현재 편집 중인 파일
- 선택한 코드
- 오류 상태
- Git 상태

### 명시적 컨텍스트
- #파일명, #폴더명, #심볼 등으로 직접 지정
- 웹 페이지나 이미지도 포함 가능

---

## 5. 컨텍스트 관리 팁

- 새 작업은 새 세션으로 시작하기
- 전체 코드베이스를 다 넣기보다는 관련 파일만 넣기
- 반복 규칙은 커스텀 지시사항으로 저장하기

---

## 6. 컨텍스트 윈도우 한계

대화가 길어지면 모델이 처리할 수 있는 정보량이 제한됩니다. 이때는 자동 요약이나 수동 압축이 일어날 수 있습니다.

---

## 7. 핵심 정리

좋은 결과를 얻으려면, AI에게 “정확한 상황 정보”를 충분히 주는 것이 가장 중요합니다. 컨텍스트를 잘 관리하는 것이 곧 AI 활용 능력입니다.
