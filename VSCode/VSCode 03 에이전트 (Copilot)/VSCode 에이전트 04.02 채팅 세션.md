# VS Code 채팅 세션

원문: https://code.visualstudio.com/docs/chat/chat-sessions

---

## 1. 한 줄 요약

채팅 세션은 AI와의 대화 기록과 컨텍스트를 하나의 단위로 관리하는 기능입니다.

---

## 2. 왜 중요한가?

한 번의 작업은 여러 번의 대화로 이어질 수 있습니다. 세션을 나누면 다음이 가능합니다.

- 서로 다른 작업을 분리해서 관리하기
- 긴 대화를 깔끔하게 유지하기
- 특정 작업에 맞는 컨텍스트만 유지하기
- 작업을 이어서 진행하거나 나중에 복구하기

---

## 3. 주요 기능

### 새 세션 시작
- 새로운 주제로 작업할 때 새 세션을 시작하면 AI가 더 관련성 높은 답변을 줄 수 있습니다.

### 세션 목록 관리
- 실행 중인 세션, 완료된 세션, 보관된 세션을 구분해 관리할 수 있습니다.
- 중요한 세션은 고정해 두는 것도 가능합니다.

### 세션 포크(Fork)
- 현재 대화를 기준으로 새로운 분기 대화를 만들 수 있습니다.
- 기존 흐름을 유지하면서 다른 방향을 실험하기 좋습니다.

### 내보내기
- 채팅 세션을 JSON이나 Markdown으로 저장하고 공유할 수 있습니다.

---

## 4. 실무 팁

- 같은 주제의 작업은 하나의 세션에서 계속 진행하는 것이 좋습니다.
- 주제가 바뀌면 새 세션을 여는 것이 더 정확한 결과를 만듭니다.
- 긴 세션은 포크나 보관을 활용해 정리하면 관리가 쉬워집니다.

---

## 5. 핵심 정리

채팅 세션은 AI와의 작업 흐름을 구조적으로 관리하는 단위입니다. 세션을 잘 나누면 컨텍스트 오염을 줄이고, 작업의 재사용성과 추적성을 높일 수 있습니다.
